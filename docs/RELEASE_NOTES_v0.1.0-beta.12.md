# Beta12 · 0.1.0-beta.12

Beta12 面向 macOS 13+ Apple Silicon 与 Windows x64，完善聊天反馈、网页读取、图片附件、提醒改期和弦轨日期调整。保留 ASTaria 的既有主题、玻璃和黑洞风格，继续记录历版优化及省电取舍。Windows 仍为未签名试验包，切页和展开聊天的卡顿待独立复测，本版实机体验不能视为已通过。

## 已实现的改动

### 聊天正文、未完成提示与回执

部分操作失败时保留析熙生成的正常回复，独立的「尚未完成」只列具体失败原因，不再用「已保存的部分」清单覆盖正文。已保存的事实放在可核对、可撤销的回执里。排程标题简化为「安排 N 段任务时间」，具体日期和起止时刻只在明细出现一次；未知估时的暂定预留说明仍保留。

执行成功以实际数据库写入核验为准。全部操作已保存而模型回复中断时，显示独立系统提示和已有回执，重试不再次执行写入。未完成提示随消息持久化，并进入备份、后续上下文和历史摘要；撤回对话不等于撤销已执行的业务修改。旧版被模板替换的历史正文无法恢复。

### 网页直取与图片附件

联网搜索默认关闭。开启后，工具收到完整 HTTP/HTTPS 地址时直接从本机抓取公开 HTML 正文，绕过关键词搜索和搜索 API Key 读取；普通关键词继续使用 DeepSeek 搜索。工具说明要求保留用户的完整网址。本仓库 `https://github.com/Wason-dev/ASTaria` 已实际取得包含 README 的正文。

网页抓取最多读取 512 KiB，提取 6,000 字符，总超时 8 秒、最多三次重定向。每跳重新验证公网 IPv4、协议和端口并固定连接地址；拒绝本机、私网、带认证网址和不允许端口。不登录、不执行页面脚本，不支持 PDF、需要浏览器渲染的正文或仅 IPv6 站点；网页内容不会取得本机写入权限。无可核实正文时的固定搜索兜底仍待改进。

首页与工作台聊天支持上传一张 PNG、JPEG 或 WebP，最大 2 MB，发送前可移除。附件随当前请求传给所选模型，保存在本机 SQLite 与 JSON 备份，支持重试和撤回上下文；图片不进入共享目录操作同步。需要支持视觉输入的模型，实际识图、真实模型下载、推理和工具调用未验收。

### 提醒与弦轨

修改事项安排时间后取消旧预约并按新时刻重建。macOS 原生预约标识包含触发时间和显示内容摘要，防止同一事项 ID 继续使用旧预约；预约修改、删除和完成的链路均有回归检查。Windows 当前只有 App 内提醒摘要与状态，尚未支持系统弹窗和原生预约。操作系统的通知授权、专注模式、关机等仍会影响送达，自动化预约检查不等于真实弹窗验收。

三日弦轨只重排真正变化的日期：今天已经满，不再阻止仅修改明天的方案；未修改日期保留原安排。仍核对真实空档、锁定、时长、截止和并发日程版本，整批保存或不写入，回执可撤销。

### 两端性能与省电策略

地平线缓存相同输入的曲线采样，尺寸、投影、指针或拉伸变化时才重建，保留原曲线公式和显示细节。此项属于避免重复计算，不宣称新的实机 FPS 或功耗提升百分比。

Beta12 明确把工作台、余时、日程、设置的黑洞与环境渲染上限从历史 60 改为 **30 FPS**，macOS 与 Windows 使用同一策略。推荐首页/聊天目标 60 FPS；手动首页/聊天 30/45/60/90/120 均保留，返回首页恢复所选档位。独立画质、分辨率、采样和特效参数不因上限下降而改变，推荐档仍按持续负载自适应画质。

30 FPS 是降低背景更新频率的省电取舍，会影响动效顺滑度，不是画质不变且帧率不变的加速收益。此上限不限制 DOM、输入或显示器刷新率。玻璃几何不变时复用位移图，CSS 背景采样仍随运动黑洞变化；独立玻璃可变刷新率控制器、全局静置 0 FPS 和新的实机功耗结论尚未实现或取得。

### 文档与展示

README 仅保留最新版本说明，演示周包含假期、两种临时课表、课程地点、单日活动、已排任务与截止；截图使用真实界面及虚构数据。安装说明、功能、安全、UI 规范与历版性能记录同步维护，安装说明的三个源码副本与发布 `install.txt` 保持一致。

## 支持范围与未完成项

- macOS 13+ Apple Silicon：ad-hoc 签名，未 Apple 公证；DMG 只提供 Applications 快捷方式，首次安装由用户拖拽。Intel Mac、iOS、Android 暂无安装包。
- Windows x64：提供 NSIS 安装 EXE 和完整 portable ZIP，EXE 未代码签名。当前包实机安装、交互及真实自动升级/失败回退未验收；Windows 11、更多 GPU/DPI/多屏、休眠和长期功耗未验收。Windows 卡顿反馈仍待独立复测。
- 标准安装版沿用 Beta11 的应用内更新；便携版和非标准安装位置手动更新，BetaX 首次升级也须手动安装。两端都需校验固定公钥的发布清单、大小与 SHA-256；不覆盖用户数据。
- 两端系统提醒能力不同：macOS 可预约关闭 App 后的提醒；Windows 当前只有 App 内提醒摘要与状态，尚未支持系统弹窗和原生预约。
- 共享文件夹/Syncthing 沿用既有加密操作协议；后续目录优化、实际 Syncthing 跨机传输和临时调课后自动重排全部余时未完成。回执只证明本机处理结果。
- 搜索无正文的固定模板、思考数字亮度调整及独立玻璃可变刷新率控制仍待后续完善；本版不把这些规划列为已完成。
- 图片传输与持久化已接入，真实模型识图、下载、推理和工具调用未验收。
