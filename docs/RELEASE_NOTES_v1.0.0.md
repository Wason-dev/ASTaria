## 这次更新的重点

- 析熙更直接地处理事项和安排，补齐长思考、流式中断、重试和真实执行回执之间的衔接。
- 支持从课表截图和 ICS 文件进入可编辑的导入流程；首次使用可以直接快捷设置、配置模型和导入课表。
- 手机重新组织信息和操作位置，保留 ASTaria 原有字体、留白、玻璃、黑洞和动画语言。
- 手机玻璃深浅独立于界面主题与通透/磨砂：默认淡档减弱原底色的遮盖，保留原主题 RGB；首次设置与正式设置均可调整，主面板和浮层共用。桌面成熟材质保持原参数。
- 日程、余时、弦轨和回执之间的安排逻辑更完整；桌面单日改为横向时间布局。
- 补齐表格、数学公式、上下文用量、思考状态和黑洞数字亮度等日常细节。
- 集中处理玻璃闪烁、弹层合成、启动和长对话重复计算，并准备四个平台的本地候选与安装流程。

## 事项集合与浮层细节（10/20 源码，未打包）

- 同主题、同 DDL 的批量作业可归为一个集合，首页和工作台默认收拢。每份事项仍独立安排、估时和完成，跨学科、分批 8＋2 创建保留同一个集合；无关的同日期事项独立显示。
- 工作台提供「归类事项」，已有任务可筛选多选、整批保存和撤销；其他窗口改过的数据需重新读取，不覆盖新内容。集合元数据随现有备份与任务同步保存。
- 创建回执收拢共同信息，展开后按项修改 DDL 或将估时发回析熙重排，保留原批次撤销。模型自然回复与部分失败提示保留。
- 集合图标与名称同行，详情居中、桌面双列，按实际安排时间排序；窄屏单列。共用浮层收敛重复亮边、统一采样/圆角轮廓，并参考工作台专注曲线调整进退场。
- 对共享浮层的底层玻璃合成继续回归，验证通透/磨砂、深浅主题与上下文/历史等入口；以本轮验收记录为准，不沿用此前关于边缘或闪动已经全部修好的结论。原生设备验收仍待完成。
- 2026-10-21：修正工作台返回首页时“交给析熙”胶囊的玻璃晚一拍出现；首页采样宿主保持完全不透明，回程第一帧即恢复取样；文字与着色层单独入场。上下文与对话记录浮层不再隐藏整个首页玻璃，改由任务详情同款遮罩、模糊和前景折射建立层次，后方内容仍保持可见。

## 析熙：对话、思考与执行

- **减少无谓犹豫。** 调整工作提示词，让明确的事项先执行必要读取与排程，只在缺少关键条件、放不下或需要改动已确认安排时询问；减少反复读同一份数据和只解释不执行。实际等待仍受模型与网络影响，不承诺固定响应秒数。
- **不靠强行截断换速度。** 撤掉思考模式与工具后续轮次中不合适的短输出预算，保留用户选择的思考深度与等待设置；避免思考占满短额度后正文或工具工作未完成。
- **流式与失败恢复。** 处理不完整流、意外结束和重试状态；重试沿用请求身份，避免重复创建。正文、执行失败和真实保存结果分别显示，口头说“完成”不充当回执。
- **思考小标题。** 等待时在三个点旁显示当前处理的小标题，沿用中性色；开始输出正文后移除。思考正文仍可展开、收起和复制，没有删除完整查看能力。
- **聊天细节。** 等待状态及时出现；复制反馈保持原按钮位置和宽度，不在正文下额外挤出“已复制”；去掉重复的生成状态。
- **表格与数学排版。** Markdown 表格使用轻分隔线与透明底，保持首页一体感；分式、次方、下标、根号等通过本地数学排版显示，复制仍保留原文。窄屏长公式与表格独立处理溢出。
- **模型上下文圆环。** 模型名旁显示最近一次请求的上下文占用；DeepSeek 按 1M 容量展示，区分提供方用量和估算，缓存不重复计数。未知自定义模型容量不编造上限；切模型、新会话与撤回时同步处理状态。模型容量与应用主动压缩上下文的预算是不同概念。
- **简化首页输入区。** 删除「只记为事项」入口及其独立保存逻辑，保留模型用量、图片入口与「发给析熙」。仍能在对话中明确要求只记录、不安排时间。
- **对话记录融入首页。** 历史列表复用首页详情／用量浮层的玻璃、圆角与进出动画，取消独立实色深底；保持重命名、切换话题、删除确认和关闭后焦点恢复，异步加载后尺寸及时更新。
- **PDF、Word 与表格阅读。** 首页与工作台复用同一附件入口，单文件上限10MiB；支持PDF、DOCX、XLSX/XLS、CSV/TSV。文字按页/段读取，表格保留工作表、单元格坐标、公式与缓存标注；PDF图像页转为本机JPEG供视觉模型读取。长文档可继续读取，保留原文件、取消、重试、撤回与备份；不把原始文件Base64当文字上下文，也不将未提取部分说成已读。旧.doc需另存为DOCX或PDF，Word嵌图、表格图表和宏不在本轮提取范围。
- **图片与网页资料。** 单张 PNG/JPEG/WebP 上限从 Beta12.1 的 2 MiB 提高到 10 MiB，保持原图，不静默压缩；改善异步读取、失败重试和附件保留。网页读取过滤无效导航壳，来源折叠去重，抓取失败由析熙自然解释，不以模板覆盖回复。手机任意网站直取和其他搜索提供方仍有限制。

## 事项、回执、余时与弦轨

- **记录日期不等于占用时间。** 考试、生日、纪念日和截止日期可以只保存事项与已知日期，不再默认占用 30 分钟；执行型任务仍按真实空档安排。
- **回执改估时后重新排程。** 重新选择预估时长会交给析熙读取同一事项与最新日程，保留已确认日期、窗口和 DDL，检查冲突后重新安排；放不下或涉及其他已确认安排时先询问取舍。
- **隐藏自动生成的操作请求。** 估时选择产生的长指令不再作为用户气泡展示；析熙保持自然回复，真实变更回执与撤销继续显示。草稿、附件、失败重试及实际保存核验保留，不套用固定回复模板。
- **弦轨使用最早的真实空档。** 调整日期时不再为了保留原时刻而跳过更早的可用窗口。当前空档只剩一部分时，在符合分段约束的情况下提供“先用剩余空档分段／保留完整一段／先不改”，选择前不写日程。
- **排程与撤销保持一致。** 分段保存保留总时长、日期、DDL、顺序及固定占用；本地重新核验后整批保存、一起撤销。重复事项与余时目标的单次安排不强行拆分。
- **历史重叠不阻止新课表。** 新增、修改、导入每周安排及同步应用时，不再被已经结束的历史冲突阻挡；正在持续与未来的真实冲突仍检查，历史完成和锁定记录保留。
- **临时调课后处理冲突。** 当天改用另一星期的课表时，只尝试移动同日尚未开始、未锁定的冲突任务，保留时长、日期和截止；无空档就保留原安排并说明原因。课表与移动结果一起撤销，不扩张为任意跨日自动改排。
- **桌面单日横向布局。** 在主概览面板下方，按时间横向排列课程、活动、任务和已知空档，只有真实重叠才上下并列；减少按类别纵向堆叠与滚动，保留日期切换动效及原事项编辑入口。极端密集、重叠内容仍需保证可读性，不承诺所有数据都能无滚动容纳。
- **日历切换与表单一致性。** 复用未变化的日历结果，处理刷新竞态；调整事项、每周安排、截图导入及 ICS 面板的尺寸、留白、网格与玻璃，向日程既有材质统一。
- **首页当天事项去重。** 选中今天时只展示当天事项与活动，不再追加同样内容的“今日待办”；查看其他日期时保留今日对照，DDL 与未定日期仍独立显示。
- **弦轨操作避让通知。** 进入、停留及退场期间隐藏右下角首页通知，包括其按钮和播报节点；退出后恢复，暂时通知在此期间保留，避免遮挡“取消／完成”。
- **首页活动编辑材质一致。** 使用首页详情玻璃与当前深浅／通透／磨砂偏好，保留后方日程，通过任务详情同款轻遮罩和前景模糊建立层次；保留活动校验、保存、删除确认及原入口焦点。
- **弦轨快速修改 DDL。** 事项因截止日期无法换天时，可以在原限制提示旁直接改日期、时刻或清除DDL；保留已拖好的分组和日期草稿，重新核对最新约束后继续完成排程，避免退出弦轨另找事项。

## 首次使用、模型连接与课表导入

- **更少步骤开始使用。** 首次进入可快捷设置并导入课表，也可直接开始；导览可收起，避免挤压被介绍的工作区。
- **解释 API Key 和本地模型。** 区分 API Key、网页登录与订阅，提供 DeepSeek 官网入口及逐步配置说明；桌面同时说明本地部署和云端 API 的选择。
- **桌面模型连接预设。** 增加 OpenAI、百炼、硅基流动、智谱等常用预设及 OpenAI 兼容的自定义地址和模型名，密钥按连接端点分别保存。各服务的工具调用、视觉与搜索能力并不相同，不能视为已逐家实测。手机云模型当前仍限 DeepSeek。
- **截图识别按步骤进行。** 选择图片、识别、选课／分组、核对与确认保存分开呈现，返回保留草稿；等待时显示实际识别阶段，支持取消，不展开导入过程中的思考正文。
- **复杂总课表选课。** 课程代码按截图原样保留并去重，按科目分组多选；`Econ1` 与 `Econ2` 等不同代码不合并、不翻译。选中代码匹配全周出现的位置，有分组条件时再选一次并复用到全周。
- **不猜认不出的内容。** 提取课程代码、星期、表头节次／时间与可选教室；不提取或展示教师姓名，忽略时间线、虚线高亮和日期装饰。未知单元格保留待补状态，不能编造课程、时间或教室。
- **可编辑确认与撤销。** 预览中逐条修改或删除，再明确确认写入周课表；教室作为次要信息，不要求逐条强制核对。保存前重新校验，完成后有可撤销回执。
- **精细识别选项。** 可配合原图及最多六张保留表头的局部图读取密集课表，选择控件与圆角沿用产品语言；不代表复杂截图识别已达到百分之百准确。
- **ICS 作为第二种导入。** 本地解析，提供范围、预览、确认与撤销；仅支持已实现的重复、时区与事件规则，不能把任意 ICS 都标为完整支持。
- **区分表格阅读与课表导入。** 聊天可上传 `.xls/.xlsx/CSV/TSV` 供析熙读取，专门的 Excel 课表上传向导尚未实现；不能把阅读成功当成课表已经保存。

## 手机体验与统一视觉

- **沿用 ASTaria 的视觉语言。** 手机继续使用共享组件、原有黑洞首页、字体、控件与动画，通过重新排版适配竖屏；不采用曾被否定的独立手机壳或额外析熙导航。
- **缩减重复信息与纵向占用。** 紧凑排列标题和分区切换，设置六个入口以两列三行呈现，减少冗余返回按钮；调整导航展开、目标操作、按钮与文字间距。
- **选择浮在原界面上。** 使用统一的浮动选择面板，避免多进一层页面；设置及子面板共用外壳、玻璃与进出动效，处理切换闪现、尺寸不一致和焦点边框裁切。
- **手机日历区别于桌面。** 周摘要无需在内部左右滚动，日视图聚焦当天，月视图选择日期；保留“周概览”和“单日明细”的区别，文字与命中区域按窄屏检查。
- **键盘与系统栏。** 编辑时稳定背景布局高度，前景输入区适应可见高度，处理安全区和系统栏；旧 WebView 缺少新版 `AbortSignal` API 时继续读取数据、设置密钥并显示首次引导。最终 Huawei 和 iOS 原生输入法体验仍待复测。
- **构图与文字。** 竖屏黑洞右移，让吸积盘进入左半边；按场景控制正文和输入字号，iOS 输入保留避免自动放大的字号，处理工作台和设置文字发糊及页间间距差异。
- **手机默认磨砂。** 新手机配置默认柔和磨砂，保留已有手动选择。Android 的自动玻璃使用系统通透／磨砂，精细折射仍可手动选择；这是边缘视觉与性能的明确取舍。

## 玻璃、黑洞与动画细节

- **稳定首页折射。** 处理玻璃采样层和重绘时机，修复手机预览中边缘折射反复出现、消失的问题；已有用户预览确认，原生设备仍需复测。
- **弹层保留后方界面与玻璃。** 用量、对话记录、活动、集合与选择面板沿用任务详情的轻遮罩与自然模糊，不挖洞、不隐藏底层文字或替换底层取样，修正打开弹层后全页磨砂与折射失效。
- **首页浮层边缘与关闭交接。** 活动编辑、对话记录和上下文面板按事项详情校准圆角与清晰轮廓；共享一层均匀取样和清晰中性内轮廓，移除局部遮罩与底层取样切换，处理关闭时整张首页卡片闪动。
- **关闭不闪露背景。** 底层采样始终不变，关闭只淡出当前弹层自己的材料和内容；覆盖动画反转、连续开关与减少动态效果。调整用量面板轮廓、圆角和像素对齐，减少边缘发糊；不增加稳态逐帧重算。
- **浅色场景连续。** 处理日程、余时进入弦轨及相关浮层的偏色与亮度跳变；局部材质统一以成熟日程面板为参照，保留首页自己的成熟材质。
- **老 GPU 的黑洞查表精度。** 光线路径表保持 Float32，平滑插值在着色器中完成，移除因缺少浮点线性过滤能力而降为半精度的路径，针对细纹理碎块问题。旧 iPad 真机仍待验收；从半精度路径迁移会增加约 6 MiB 查表显存，不标为零代价修复。
- **思考数字亮度可调。** 黑洞 `01010` 数字默认提亮，设置提供 50%–300% 独立亮度，默认 125%；不改变全局曝光、盘面亮度或画质。
- **弦轨外观设置收敛。** 移除普通设置中的四项过细调节，保留既有保存参数与实际效果，避免让日常使用承担调试复杂度。
- **任务步骤与指针光感。** 工作台步骤上下页有方向一致的退场和入场，快速点击保留目标页，内容高度稳定。将原有指针光感补到专注步骤中间面板、简报外壳及共享浮层，已有面板光效保持；触摸不触发，减少动态偏好保留。
- **首页胶囊轮廓。** 补齐分离取样层的圆角裁切，消除收起状态右端露出的直边，保留原光学参数和投影。
- **动画和功耗策略保留。** 面板、日期、场景切换有进入和退出过程，支持系统减少动态效果；工作区停稳后仍按 30 FPS 预算运行，转场遵循所选帧率，画质档位独立。

## 性能、数据与平台准备

- **启动少阻塞。** 确定性的黑洞 LUT 积分移到启动 Worker，结果转移并缓存；手机工作区按需加载，桌面目录扫描与提醒初始化延后到首屏显示。
- **长对话少重复工作。** 静态历史消息与流式正文分离，复用相同快照和 Markdown 结果，减少无变化重绘、重复读取及图片编码。
- **本机数据读取更轻。** SQLite 缓存编译语句而不缓存查询结果；只读请求不再导出整库，无变化启动不重复保存，导出后恢复约束。保留保存确认、失败回滚和数据边界。
- **后台与可见性一致。** 原生 inactive 与页面 hidden 同步控制轮询、时钟和动画；合并同时进行的相同 GET，取消过期请求，减少重复 DOM 写入、几何计算与不可见绘制。
- **同步减少无效扫描。** 已验证且未变化的文件不反复读取；变化、失败、待处理及手动检查继续完整核验。真实 Syncthing 跨机传输和长期负载仍待完成。
- **图标以用户提供的成稿为准。** 桌面使用放大的透明底图标，Mac 应用、提醒助手与 Applications 替身一致，Windows 内嵌各尺寸资源同步；手机保留黑底。未重新设计标志、添加渐变或改成纯白。
- **DMG 安装引导。** 使用 ASTaria 风格背景和拖入 Applications 的提示，关键安装与打开说明放到下方独立位置；不内置关闭系统保护或自动改签名的脚本。
- **移动工程与分发准备。** Android/iOS 复用共享业务与 SQLite，原生密钥、提醒、备份分享已有实现；Android 现阶段是 debug APK，iOS 先走 TestFlight，尚无 IPA 或上传记录。
- **官网链接。** README 与正式发布说明都保留 [astaria.space](https://astaria.space) 和 [官网仓库](https://github.com/Wason-dev/ASTaria-website)。

性能测量条件、仍存在的首开长任务和视觉取舍见 [PERFORMANCE.md](PERFORMANCE.md) 与 [POWER_AND_RENDERING_DECISIONS.md](POWER_AND_RENDERING_DECISIONS.md)。桌面模拟、源码测试数量和静态包核验均不能代替 Windows、Mate XT 或 iPhone/iPad 的真实流畅度、GPU 与耗电验收。
