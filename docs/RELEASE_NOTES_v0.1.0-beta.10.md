# BetaX · 0.1.0-beta.10

BetaX 同时推进 Windows 试验版、三项日程/析熙修复，以及共享文件夹与 Syncthing 目录两种无需 ASTaria 自建服务器的同步方式。技术标签为 `v0.1.0-beta.10`，GitHub 展示名称为 **BetaX**。

## 本次实现

- 假期使用正确日期标签，不再显示为「临时调课·周六课表」；第一次设置假期会移除课程占用，保留或生成可安排时段。
- 析熙默认显示当前阶段标题与一行简短工具说明；完整思考可展开，复制保留全部轮次与原始内容。
- 桌面「设置 → 数据 → 跨设备同步」支持选择普通共享文件夹或用户已配置的 Syncthing 目录。每设备继续使用独立 SQLite，只有 AES-256-GCM 加密的不可变业务操作进入共享目录；API Key、聊天、记忆、思考与本地模型配置不同步。
- 本机事务与 outbox 原子提交，接收与去重记录原子提交；重复幂等、缺序等待、损坏文件可见。同字段离线冲突需处理，删除墓碑防止旧副本复活；锁定、占用与截止重新核验。设置显示暂停、待导出、待处理原因、持久化最近检查时间和最近 20 项业务变更回执。
- 新设备通过同步目录与恢复密钥加入；恢复文件保存在共享目录外。撤销旧设备需建立新目录、新密钥和新组；旧设备已经取得的内容不能远程抹除。
- Windows x64 使用 `%APPDATA%\ASTaria`、SQLite 和 DPAPI；NSIS 当前用户安装包与 portable ZIP 使用 ASTaria 图标，用户数据与程序目录分开。portable 表示无需安装，数据仍属于当前 Windows 用户。
- 完整 GSAP 许可正文、第三方声明、Electron/Chromium 许可随包提供；修复桌面包遗漏 `htmlparser2` 服务端依赖。安装说明资产统一为小写 `install.txt`，版本目录沿用 beta6 命名格式。
- Windows 窗口不使用独立应用菜单或系统原生标题条：保留原生三按钮，用透明可拖动区域承担顶部拖动与双击最大化，与应用场景融合。工作台与余时使用 8px 主题滚动条（透明轨道、圆角中性 thumb、悬停少量金色、无上下箭头），深浅主题都可见。
- Windows 默认使用 CSS 通透/磨砂玻璃：保留 rim、tint、反光及通透与磨砂差别，但不做 SVG 精细边缘位移；设置 → 外观与动画 → 玻璃渲染可切到「精细折射」换回该位移。**这是明确的材质取舍，不是无损画质优化**：黑洞的最高画质、渲染分辨率、采样与辉光均未降低，取舍只影响玻璃合成路径。取舍依据是实测帧率（见下方性能一节），Windows 10 x64（19044）· RTX 4090 Laptop · D3D11 · 2560×1400 CSS · DPR 1.5 · 实际黑洞 3824×2091 ultra · 每样本 8 秒：工作台 37.30 → 59.99 FPS、余时 21.48 → 59.98 FPS；同构建切「精细折射」为工作台 40.91、余时 23.24，首页约 59.97 / 59.99，浅色磨砂余时 58.61。完整方法与限制见[渲染与后台性能](PERFORMANCE.md)。
- 首次设置新增帧率与独立画质：推荐档目标 60 FPS、从最高画质开始、持续卡顿时自动下调并在流畅后恢复；手动档可选 30/45/60/90/120 FPS 与最高/高/轻量/兼容，手动档保持固定，其他工作区最高 60 FPS。工作台引导区分读取中、读取失败、空工作台与存在真实事项四种状态。四组外观、推荐与手动保存、窄屏以及工作台四种状态已通过隔离 UI 验证。

## 平台与功能限制

Windows 为未签名试验版，Windows 11、原地升级、休眠、更广 DPI（目前只有 DPR 1.5 的一种配置）、多屏和长期 GPU/功耗尚未验收；没有 Windows App 内自动更新和退出后提醒。安装与卸载已用最终发布 `setup.exe` 在隔离中文路径目录实测通过（含占用 EXE 失败不改文件、卸载保留无关用户文件、真实 AppData 未变）。macOS 为 ad-hoc 签名、未做 Apple 公证，系统通知显示与干净机器首次启动仍需验证。不以构建成功代替运行验证。

本地模型使用用户预先启动的 Ollama 或兼容服务。ASTaria 可以向 Ollama 请求下载受支持模型，但不会安装 Ollama；协议测试不等于真实模型下载、推理性能或工具调用能力已验收。

Syncthing 必须由用户自行配置并共享目录，ASTaria 只检测目录标记并读写同一加密协议；真实 Syncthing 跨机传送未验收。最近检查和业务回执只证明本机处理结果，不证明其他设备送达。课表与日程数组按字段整体合并，冲突可能较粗；无原始对话回执同步、跨设备撤销、日志压缩或自动密钥轮换。单操作明文上限 16 MB，单轮扫描最多 20,000 文件。

## 下载与安装

- macOS：`ASTaria-0.1.0-beta.10-mac-arm64-adhoc.dmg`。
- Windows：`ASTaria-0.1.0-beta.10-win-x64-setup.exe` 与 `ASTaria-0.1.0-beta.10-win-x64-portable.zip`。
- 同时提供 SHA-256 校验文件、构建清单和 `install.txt`。Windows 不单独分发缺少运行时依赖的 `ASTaria.exe`。

macOS DMG 根目录仅包含 App、指向 `/Applications` 的 Applications 快捷方式及说明，由用户自行拖拽安装。Windows 安装程序默认使用当前用户目录；ZIP 必须完整解压后运行。更新前先导出备份、退出旧版。同步密钥与 API Key 不包含在备份内；恢复备份前请断开同步。
