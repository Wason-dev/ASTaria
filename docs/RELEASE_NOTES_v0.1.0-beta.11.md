# Beta11 · 0.1.0-beta.11

本轮是 macOS arm64 与 Windows x64 的本地性能测试版本，重点处理切换页面、展开与收拢聊天。**尚未推送 GitHub，也未上传 Release**。公开最新版仍为 BetaX；本地两端体验反馈后再决定是否发布。

## 已实现的优化

- 帧率分区保持原有有意的省电设计：首页与聊天沿用所选 90/120 FPS，工作区的黑洞与环境渲染最高 60 FPS；30/45 档不升档，画质不随帧率上限下调，返回首页恢复所选帧率。有效帧率预算与画质未变的页面切换保留渲染调度和自适应历史；推荐设置仍以 60 FPS 为目标。
- 修复原生 RAF 时间戳波动导致的误跳帧；容差由 0.25ms 调整到 2ms，绝对截止时间仍按完整帧间隔推进，不补画过期帧。
- UI 相机快照去重，避免高刷屏反复提交同一几何；玻璃 SVG 的尺寸和图像属性只有变化才写入。
- 完整 RGBA 相同时复用位移 PNG，减少聊天形变尾段的编码与上传；比较缓存最多保留一张、上限 8 MiB，不修改位移公式或降低贴图分辨率。
- CSS 玻璃路径不再生成 SVG 或观察不需要的几何；零半径模糊改为 none，保留原 tint、rim、阴影、反光和真实磨砂半径。
- 浅色端点跳过乘数为零的辉光中间通道；光标强度精确为零时跳过无效透镜、环和光晕计算，非零参数仍计算完整效果。
- 保留工作区 200ms 退出淡出，随后停止隐藏工作区的样式/布局工作；页面 DOM、编辑器和滚动位置仍保留，返回恢复可见状态。
- Mac 打包优先使用 APFS 克隆复制临时 App，非支持文件系统回退到原复制方式，最终仍校验签名与 DMG。

## 验证口径

两端分别使用原生 Electron 与一次性数据库/配置，固定最高画质和各自实际分辨率，比较聊天展开/收拢及首页→工作台→余时→首页。覆盖默认玻璃、浅色磨砂、手动精细折射与 120 FPS；记录真实渲染帧、首秒与全程帧间隔、长任务、PNG 编码、GPU 时间。原有静置后采样会漏过交互开始的停顿，因此不作为本版主要验收口径。

位移图与独立完整像素参考比较；辉光使用真实 GPU 对照冻结的 BetaX 着色器，涵盖深浅端点、中间值、接近零的参数与实际光标效果。原生截图另覆盖深/浅 × 通透/磨砂 × 首页聊天/工作台/余时，检查布局、材质和零强度滤镜移除。

源码与原生候选已完成多轮测试；**本轮本地安装包的独立验收已完成，等待用户体验反馈**。完整性能数字与限制记入 [性能记录](PERFORMANCE.md)。

## 支持范围与未完成项

- macOS 13+ Apple Silicon：ad-hoc 签名，未 Apple 公证；DMG 仅提供 Applications 快捷方式，由用户手动拖拽安装。
- Windows 10 x64 19044：RTX 4090 Laptop、D3D11、DPR 1.5 的真实交互测试；EXE 与完整解压的 portable ZIP 共用 `%APPDATA%\ASTaria`。
- Windows 11、更多 GPU/DPI/多屏、睡眠恢复与长期功耗尚未验收。Windows 手动精细折射仍可能明显慢于默认玻璃；不能承诺所有场景无卡顿。
- Windows 仍需手动更新，没有退出 App 后的原生提醒，也未做 Windows 代码签名。
- 按用户要求没有下载模型，真实 Ollama 下载、推理与工具调用不在本版已验收范围内。
- BetaX 的共享目录/Syncthing 同步与密钥安全边界继续适用，未安装/配置 Syncthing 或修改用户真实业务数据。
