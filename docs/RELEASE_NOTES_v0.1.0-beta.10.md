# BetaX · 0.1.0-beta.10

BetaX 同时推进 Windows 试验版、三项日程/析熙修复，以及共享文件夹与 Syncthing 目录两种无需 ASTaria 自建服务器的同步方式。技术标签为 `v0.1.0-beta.10`，GitHub 展示名称为 **BetaX**。

## 本次更新

- 假期使用正确日期标签，不再显示为「临时调课·周六课表」；第一次设置假期会移除课程占用，保留或生成可安排时段。
- 析熙默认显示当前阶段标题与一行简短工具说明；完整思考可展开，复制保留全部轮次与原始内容。
- 桌面「设置 → 数据 → 跨设备同步」支持选择普通共享文件夹或用户已配置的 Syncthing 目录。每设备继续使用独立数据库，只有加密的不可变业务操作进入共享目录；API Key、聊天、记忆、思考与本地模型配置不同步。
- 同步设置显示暂停、待导出、待处理原因、最近检查时间和最近 20 条业务变更回执。新设备通过同步目录与恢复密钥加入；恢复文件保存在共享目录外。撤销旧设备需建立新目录、新密钥和新组；旧设备已经取得的内容不能远程抹除。
- Windows x64 试验版使用当前用户数据目录；安装包与便携 ZIP 使用 ASTaria 图标，用户数据与程序目录分开。portable 表示无需安装，数据仍属于当前 Windows 用户。
- 随包提供完整第三方许可正文与安装说明（install.txt）。
- Windows 窗口不使用独立应用菜单或系统原生标题条：保留原生三按钮，用透明可拖动区域承担顶部拖动与双击最大化。工作台与余时使用主题滚动条，深浅主题都可见。
- Windows 默认使用通透／磨砂玻璃，并保留反光与通透、磨砂的差别；设置 → 外观与动画 → 玻璃渲染可切换到「精细折射」，换取更精细的边缘效果但性能开销更高。**这是明确的材质取舍，不是无损画质优化**：黑洞的最高画质、渲染分辨率、采样与辉光均未降低。
- 首次设置新增帧率与独立画质：推荐档以 60 FPS 为目标，从最高画质开始按持续负载下调并恢复；手动可选 30/45/60/90/120 FPS 与最高/高/轻量/兼容，手动档保持固定，其他工作区最高 60 FPS。
- 工作台引导区分读取中、读取失败、空工作台与存在真实事项四种状态，只有真的打开事项再返回才显示已完成。

## 平台与功能限制

- Windows 为未签名试验版：Windows 11、原地升级、休眠、更广 DPI、多屏和长期功耗尚未完成验证；不提供 Windows App 内自动更新和退出后提醒。
- macOS 为 ad-hoc 签名、未做 Apple 公证；系统通知显示与干净机器首次启动仍需验证。
- 本地模型使用用户预先启动的 Ollama 或兼容服务。ASTaria 可以向 Ollama 请求下载受支持模型，但不会安装 Ollama。
- Syncthing 必须由用户自行配置并共享目录，ASTaria 只检测目录标记并读写同一加密目录；真实 Syncthing 跨机传送尚未验证。最近检查和业务回执只证明本机处理结果，不证明其他设备送达。课表与日程按字段整体合并，冲突可能较粗；无原始对话回执同步、跨设备撤销、日志压缩或自动密钥轮换。单操作明文上限 16 MB，单轮扫描最多 20,000 个操作文件。

## 下载与安装

- macOS：`ASTaria-0.1.0-beta.10-mac-arm64-adhoc.dmg`。
- Windows：`ASTaria-0.1.0-beta.10-win-x64-setup.exe` 与 `ASTaria-0.1.0-beta.10-win-x64-portable.zip`。
- 同时提供 SHA-256 校验文件与安装说明。

macOS DMG 根目录仅包含 App、指向 `/Applications` 的 Applications 快捷方式及说明，由用户自行拖拽安装。Windows 安装程序默认使用当前用户目录；ZIP 必须完整解压后运行。更新前先导出备份、退出旧版。同步密钥与 API Key 不包含在备份内；恢复备份前请断开同步。

完整边界见 [功能说明](FEATURES.md)、[安装说明](INSTALL.md)与[安全说明](../SECURITY.md)。
