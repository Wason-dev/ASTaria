ASTaria 1.0.0-rc.1 本地候选安装
=========================

技术版本 1.0.0-rc.1（展示名称 RC1）是本地未发布候选：macOS / Windows 的候选目标见下方文件名，
Android 仅供 debug 测试，iOS 只有工程、没有 IPA。候选尚未公开发布，最新公开版本仍是 Beta12.1（0.1.0-beta.12.1），其历史公开下载信息保留在文末。

候选安装包生成后，桌面打包器会在打包完成时输出配套的 .sha256 校验文件与哈希清单，只作本机核对，不是公开更新签名清单；这只适用于桌面候选产物，Android debug APK 与 iOS 工程没有 .sha256 校验文件或签名发行清单。各平台候选文件名如下，实际产物与验收结果见候选验收状态 (docs/releases/v1.0.0-rc.1-readiness.json)。请先核对随包校验文件，再按本说明安装。

桌面候选目标文件名：

- macOS 13+ Apple Silicon（arm64）：ASTaria-1.0.0-rc.1-mac-arm64-adhoc.dmg（ad-hoc 签名、未 Apple 公证）
- Windows x64：ASTaria-1.0.0-rc.1-win-x64-setup.exe（NSIS 当前用户安装程序）与 ASTaria-1.0.0-rc.1-win-x64-portable.zip；不做 Authenticode 代码签名
- Android：Gradle debug 构建与 lint 通过；只有 debug APK，仅供本地测试，未做正式签名，未实机验收
- iOS：只有工程，缺少完整 Xcode 与签名，没有 IPA；后续先走 TestFlight 流程

候选验收状态：Windows 本版实机安装与交互、Windows 11、自动升级与失败回退均未验收。正式 Developer ID Application 签名与 Apple 公证的流程已准备好，但证书尚未配置，见 macOS 签名与公证说明 (docs/MACOS_SIGNING.md)。候选功能范围与逐项边界见 README (README.md) 与功能详情 (docs/FEATURES.md)；各平台详细验收结果见候选验收状态 (docs/releases/v1.0.0-rc.1-readiness.json)。图标采用银灰三瓣黑底 astaria-icon.svg 原样导出到四端，导出方法与输出表见图标说明 (design/icon/README.md)。

macOS 13+ · Apple Silicon
=========================

ASTaria 1.0.0-rc.1 · RC1 本地候选 · macOS arm64

系统要求：macOS 13 或更新版本，Apple Silicon（M 系列芯片）。不支持 Intel Mac。
此包采用 ad-hoc 签名，未经 Apple 公证。

安装（候选 DMG 生成并完成本机核验后适用）
1. 退出正在运行的旧版 ASTaria。
2. 打开 ASTaria-1.0.0-rc.1-mac-arm64-adhoc.dmg（候选目标名）。
   根目录可见 ASTaria.app、指向 /Applications 的 Applications 快捷方式与底部单行安装说明。
   深色背景的箭头说明拖拽方向，下方直接展示关键步骤；完整说明可双击文字入口打开。
   把 ASTaria.app 拖到 Applications 快捷方式上；首次安装由用户完成拖拽，
   DMG 不含自动复制脚本。
3. 从「应用程序」打开 ASTaria，安装后可推出磁盘映像。

可信检查（候选 DMG）
候选没有公开 Release，因此没有公开下载链接或公开发布哈希。桌面打包完成后会在产物旁
生成配套的 SHA-256 校验文件（形如 ASTaria-1.0.0-rc.1-mac-arm64-adhoc.dmg.sha256）
与哈希清单 manifest，可先在本机核对再安装。请只安装自己构建或确认来源的文件，并在本机
核对 DMG 与 App 的签名（ad-hoc 签名不证明发布者身份）。请以产物旁的校验文件为准，例如：
shasum -a 256 "ASTaria-1.0.0-rc.1-mac-arm64-adhoc.dmg"
如需验证签名完整性，可在终端运行：
/usr/bin/codesign --verify --deep --strict --verbose=2 "/Applications/ASTaria.app"

如果打不开
先正常尝试打开一次。如果提示无法验证开发者，到「系统设置 → 隐私与安全性」
找到 ASTaria，选择「仍要打开」并按系统提示确认。这是 ad-hoc 本地包的既有边界，
本包不提供自动复制、关闭 Gatekeeper 或重新签名的脚本；也不要为它关闭全系统安全设置。

系统提醒
在「设置 → 通知」开启「关闭 App 后仍提醒」，按系统提示允许 ASTaria 提醒。
预约交给 macOS，无需 App 常驻；覆盖未来 30 天内最近的 64 条，打开或恢复时补充。
修改安排时间后会取消旧预约并按新时刻重建；完成或删除也会取消。
免打扰、系统专注模式和关机会影响送达，原生送达仍需设备验证。

安装包不含开发者的课表、事项、聊天、记忆、密钥或数据库。首次使用需自行设置模型，
录入课程和安排。此版本沿用已有 ASTaria 本机数据，请避免网页和桌面同时修改同一份数据。

Windows x64（本地候选）
=================

候选目标：ASTaria-1.0.0-rc.1-win-x64-setup.exe 与 ASTaria-1.0.0-rc.1-win-x64-portable.zip，
不单独分发缺少运行时的 EXE。未做 Authenticode 代码签名，
本版实机安装、交互、Windows 11 与自动升级/失败回退均未验收。

ASTaria 1.0.0-rc.1 · RC1 本地候选 · Windows x64

1. setup.exe：双击运行，按提示安装后从开始菜单或安装目录启动，无需管理员权限，
   按当前用户安装到 %LOCALAPPDATA%\Programs\ASTaria。
   portable.zip：完整解压到新目录，再运行其中的 ASTaria.exe，不要只移动单个 EXE。
2. 数据目录为 %APPDATA%\ASTaria。安装与便携共用当前用户数据；卸载会删除程序、
   快捷方式与卸载注册项，不删除用户数据。
3. 应用内更新沿用与已发布版本相同的实现（核对发布清单 Ed25519 签名、SHA-256 与大小后
   安装并重启，启动失败尝试回退）。该更新通道目前只有已有实现与自动化协议检查，
   本版实机安装、更新与失败回退均待验收。
   此候选版本尚未作为公开更新源发布；未来正式发布仍须通过发布清单验签与
   版本比较，本版到正式版的实际升级待验收。
4. 便携版与其它安装位置需手动更新；退出旧版后完整解压新包或运行新 setup.exe。
5. 在浏览器运行源码不提供 DPAPI 和文件夹同步，两项需要 Electron 桌面包。

边界：未做 Authenticode 代码签名，不承诺 Windows 11 体验；Windows 10 历史测试
不能代替本版成品验收。更多 GPU、DPI/多屏、休眠恢复、长期功耗与 Windows 原生
通知显示未验收。

首次设置、模型与外观
==========

首次启动可以一次保存快捷设置，也能展开调整个性、主题、玻璃、帧率和画质；
首屏可截图导入课表或导入 ICS。模型连接可稍后配置，功能导览可收起或直接开始，不挤压工作区。

API Key 是开放平台调用凭证，不是登录密码或聊天会员；API 费用由供应商按调用量结算。
DeepSeek：打开 https://platform.deepseek.com/ → 登录或注册 → 核对 API 账户余额与用量计费 →
在 https://platform.deepseek.com/api_keys 新建密钥 → 复制到引导的密码框 →「保存并测试连接」。
不要把密钥发到聊天或截图里。桌面还可在模型设置选择 OpenAI、百炼、硅基流动、智谱预设，
或填写 OpenAI 兼容 HTTPS 基础地址和模型 ID；对应密钥单独保存，测试连接后再使用。
供应商需支持所选模型的工具/视觉输入；地址预设不代表已逐家验收。手机暂只支持 DeepSeek。

截图导入先识别草稿；总课表选自己的原始课程代码、按需选组，最后在可编辑预览中核对
星期、节次与钟点。不识别教师，教室可空，认不清的格子需补齐或移除；确认才写入并可撤销。
可选「拆图」保留原图并附带表头裁片，不能保证消除误读。ICS 本地解析且无需密钥，
只支持有限的实际日期与每周/隔周规则；全天、跨日、无限重复等不支持项会明确提示。
「ASTaria 推荐」从最高画质开始，首页/聊天目标 60 FPS，持续负载不足时下调并逐步恢复；
手动画质保持固定，首页/聊天与相机页面帧率可选 30/45/60/90/120。工作台、余时、日程、
设置背景在相机停稳后最高 30 FPS，相机运动期间（含余时与弦轨飞行）沿用所选首页帧率，
返回首页恢复选择。画质独立。这个省电上限只影响环境渲染，会降低背景动效更新频率，
不限制输入、DOM 或显示器刷新率；它不是无损加速，独立玻璃可变刷新率与全局静置
0 FPS 尚未实现。

联网搜索默认关闭。桌面版开启后，完整 HTTP/HTTPS 链接由本机抓取公开 HTML，普通关键词发送到
DeepSeek 搜索通道；独立搜索请求不携带课表、聊天或记忆。网页抓取不登录、不执行脚本，
拒绝本机和私网地址，并过滤 GitHub 登录与导航壳；抓取失败交由模型自然回复，不用固定
段落覆盖正文，来源作为正文外的默认折叠去重列表。

首页和工作台专注聊天均在「发给析熙」左边提供圆形 ＋，可选择图片；也可直接拖图进
ASTaria。候选单张支持 10 MiB 的 PNG/JPEG/WebP，最长边 8192、总像素 16777216，
原图不压缩；已发布 Beta12.1 仍是每条 2 MiB。10 MiB 的完整发送已完成本机真实界面接收、
存储失败重试与刷新断线重试验收，字节一致、不压缩、不缩放；真实视觉模型的理解效果仍待
验收。专注聊天打开时保留当前事项，其余正常页面打开首页聊天。拖入不自动发送，选好后在
输入框下方预览、移除，再确认发送。读取中、设置/弹层或消息处理期间不接收新发送或拖图。
云端模式把图片发给当前模型，本地模式发送到已配置的回环服务；需要视觉模型。图片保存在
本机和 JSON 备份里，不进入跨设备同步。备份不含 API Key 或同步密钥，请妥善保护并另存
同步恢复密钥。本地模型运行时需自行安装和启动，真实模型下载、推理与工具调用未验收。

临时调课仅尝试在同一天挪动尚未开始、未锁定的冲突任务，保留原时长与截止要求；
移动与课表一起保存和撤销。没有空档时保留原计划并说明原因，也可选择只改课表。
其他日程修改与跨日重排不属于此能力，详细边界见功能说明。

手机端（本地候选）
=========

- Android：Gradle debug 构建与 lint 通过；当前只有 debug APK，仅作本地测试，未做正式签名，
  也未实机验收；该 APK 只带构建元数据，没有配套的 .sha256 校验文件或签名发行清单。
- iOS：当前只有工程，缺少完整 Xcode 与签名，没有 IPA，也没有哈希清单；后续先走 TestFlight 流程。
- API Key 由 Keychain 与 Android Keystore 保护，没有浏览器明文回退。
- 手机提醒与备份分享已实现，待原生设备验收。
- 手机云模型仅支持 DeepSeek，没有本地 Ollama / LM Studio 连接，也没有共享文件夹与
  Syncthing 入口。
- 公开 GitHub 仓库与 Release 直链使用固定匿名 api.github.com 读取 README 与发布信息；
  任意网站的手机直取不支持。

跨设备同步（共享文件夹 / Syncthing 现有目录）
=============================

路径为「设置 → 数据 → 跨设备同步」，桌面版沿用已发布版本相同的配置入口与协议。

- 选择普通共享文件夹，或已由 Syncthing 共享的目录（须有 .stfolder 标记）。
  新建组使用新目录；原设备把恢复密钥导出到共享目录外，新设备加入并输入 64 位密钥。
- 每台设备保留自己的 SQLite，目录只传 AES-256-GCM 加密的不可变操作文件。
  不要复制运行中的 SQLite 及其 -wal / -shm。
- 暂停停止目录读写，本机变更继续排队；恢复后按 30 秒周期扫描，可手动检查或唤醒时检查。
  界面保留最近检查时间、待处理原因与最近 20 项事务回执，回执不证明远端送达。
- 不同字段自动合并；同字段冲突、锁定、重叠与 DDL 冲突需核对，删除墓碑阻止旧记录复活。
  日程数组按字段整体合并，可能需要人工处理。
- 同步任务、分类、课程日程、安排、目标和完成记录；历史备份上限仍为 32 MiB 的
  UTF-8 JSON 备份边界。
- API Key、模型路径、聊天及图片、记忆、思考、原始对话回执和跨设备撤销不同步。
- 退出组保留本机与共享文件。撤销设备需使用新目录、新密钥和新组；旧设备已有内容不能远程抹除。
  全部可信设备与恢复副本丢失密钥时，旧密文不能恢复。
- ASTaria 不安装或配置 Syncthing，不修改防火墙和配对。真实 Syncthing 跨机传送与后续目录优化未验收。
- 单操作明文上限 16 MB，单轮最多 20,000 文件；不压缩操作日志，长期多设备大数据未验收。
