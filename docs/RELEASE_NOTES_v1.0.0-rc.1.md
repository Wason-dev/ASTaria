# ASTaria 1.0.0-rc.1 · 本地未发布候选（历史）

`1.0.0-rc.1`（展示名称 **RC1**）是 v1.0 开发期间的本地候选构建标识，从未公开发布，也没有公开下载或更新推送。候选覆盖 macOS 与 Windows 桌面候选目标、Android debug 测试包和 iOS 工程；这些构建只用于开发验证，不作为正式发行版。

Beta12.1 之后的累计产品变化与 v1.0 的平台、分发要求统一见 [v1.0 发布说明](RELEASE_NOTES_v1.0.0.md)。最新公开版本仍为 [Beta12.1](https://github.com/Wason-dev/ASTaria/releases/tag/v0.1.0-beta.12.1)。
