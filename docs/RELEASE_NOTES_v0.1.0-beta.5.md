# ASTaria 0.1.0-beta.5

这次更新集中改善日常使用的可靠性：更容易找到心愿澄清，在每周安排里查看单双周，在专注时管理事项；同时修复长对话、初次排程、备份恢复和更新安装中的边界问题。

- **心愿与每周安排**：余时可直接保存并聊清楚新心愿；每周安排总览加入单双周查看和共用首周设置。
- **专注与时长**：专注界面提供删除与余时按次管理入口，分别显示当前预计与已排时间；专注/休息时长保存到本机设置。修改估时不会擅自伸长原时段。
- **更完整的初排**：优先完整连续时段，确实需要拆分时每段至少 15 分钟，避免普通任务的五分钟尾巴；明确的短任务仍可完整安排。无法排下的部分如实显示。
- **析熙**：高个性保留主见、嘴硬与轻松时的得意，减少固定台词和重复的温柔约束；疲惫时仍可自然表达关心。长回合较早的读取按来源收起，需要时再读，保留已保存操作及最新工具结果。
- **故障恢复**：服务断连和界面异常提供恢复入口；工具批次、失败重试和流式尾部处理更可靠。「只记录、先不安排」由执行层保护。
- **性能**：减少相机过渡引起的整页重复渲染，改善从后台回来的响应，保留现有画质设置。
- **系统提醒**：补充原生通知助手的图标注册与内容检查，设置内可发送测试提醒；继续尊重 macOS 的隐藏预览设置。
- **数据与更新**：修复事务锁冲突后的状态、相邻空档判断和余时撤销标记备份；自动更新从 beta.5 起验证独立 Ed25519 发布清单签名，缓存损坏可重新下载，安装失败会说明结果。

适用于 macOS 13+、Apple Silicon（arm64）。使用 ad-hoc 签名，尚未 Apple 公证。beta.3/beta.4 可从设置更新；这次首次升级仍使用旧版本的验证逻辑，新增发布者验证在 beta.5 安装后生效。更新前建议导出备份。

验证：`npm test` 通过 1382/1382，`npm run build:desktop` 通过，版本、许可与发布清单检查通过；隔离页面验证覆盖日程、任务步骤、余时、更新、beta.4 与 beta.5 流程。原生通知显示、实际 GPU 帧率、休眠恢复与长期功耗仍需在目标设备上验证。本版为 macOS 13+ Apple Silicon ad-hoc 内测包，未公证。
