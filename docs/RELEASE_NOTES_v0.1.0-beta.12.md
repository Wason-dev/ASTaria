# Beta12 · 0.1.0-beta.12

Beta12 面向 macOS 13+ Apple Silicon 与 Windows x64，完善聊天反馈、网页读取、图片附件、提醒改期和弦轨日期调整。保留 ASTaria 的既有主题、玻璃和黑洞风格。Windows 仍为未签名试验包，切页和展开聊天的卡顿待独立复测，本版实机体验不能视为已通过。

## 已实现的改动

### 聊天正文、未完成提示与回执

部分操作失败时保留析熙生成的正常回复，独立的「尚未完成」只列具体失败原因，不再用「已保存的部分」清单覆盖正文。已保存的事实放在可核对、可撤销的回执里。排程标题简化为「安排 N 段任务时间」，具体日期和起止时刻只在明细出现一次；未知估时的暂定预留说明仍保留。

执行成功以实际写入核验为准。全部操作已保存而模型回复中断时，显示独立系统提示和已有回执，重试不再次执行写入。未完成提示随消息持久化，并进入备份、后续上下文和历史摘要；撤回对话不等于撤销已执行的业务修改。

### 网页直取与图片附件

联网搜索默认关闭。开启后，工具收到完整 HTTP/HTTPS 地址时直接从本机抓取公开 HTML 正文，不再经过关键词搜索；普通关键词继续使用 DeepSeek 搜索。工具说明要求保留用户的完整网址。

网页抓取最多读取 512 KiB，提取 6,000 字符，总超时 8 秒、最多三次重定向；只访问公开网页，拒绝本机、私网、带认证网址和不允许端口。不登录、不执行页面脚本，不支持 PDF、需要浏览器渲染的正文或仅 IPv6 站点；网页内容不会取得本机写入权限。无可核实正文时的固定搜索兜底仍待改进。

首页与工作台聊天支持上传一张 PNG、JPEG 或 WebP，最大 2 MB，发送前可移除。附件随当前请求传给所选模型，保存在本机数据库与 JSON 备份，支持重试和撤回上下文；图片不进入共享目录操作同步。需要支持视觉输入的模型，实际识图、真实模型下载、推理和工具调用尚未验证。

### 提醒与弦轨

修改事项安排时间后取消旧预约并按新时刻重建。Windows 当前只有 App 内提醒摘要与状态，尚未支持系统弹窗和原生预约。操作系统的通知授权、专注模式、关机等仍会影响送达，自动化预约检查不等于真实弹窗验证。

三日弦轨只重排真正变化的日期：今天已经满，不再阻止仅修改明天的方案；未修改日期保留原安排。仍核对真实空档、锁定时段、时长与截止时间，整批保存或不写入，回执可撤销。

### 性能与省电策略

Beta12 明确把工作台、余时、日程、设置的黑洞与环境渲染上限从历史 60 改为 **30 FPS**，macOS 与 Windows 使用同一策略。推荐首页/聊天目标 60 FPS；手动首页/聊天 30/45/60/90/120 均保留，返回首页恢复所选档位。独立画质、分辨率、采样和特效参数不因上限下降而改变，推荐档仍按持续负载自适应画质。

30 FPS 是降低背景更新频率的省电取舍，会影响动效顺滑度，不是画质不变且帧率不变的加速收益。此上限不限制页面内容、输入或显示器刷新率。独立玻璃可变刷新率与全局静置 0 FPS 尚未实现。

## 支持范围与未完成项

- macOS 13+ Apple Silicon：ad-hoc 签名，未 Apple 公证；DMG 只提供 Applications 快捷方式，首次安装由用户拖拽。Intel Mac、iOS、Android 暂无安装包。
- Windows x64：提供安装程序和完整 portable ZIP，EXE 未代码签名。当前包实机安装、交互及真实自动升级/失败回退尚未验证；Windows 11、更多 GPU/DPI/多屏、休眠和长期功耗尚未验证。Windows 卡顿反馈仍待独立复测。
- 标准安装版沿用 Beta11 的应用内更新；便携版和非标准安装位置手动更新，BetaX 首次升级也须手动安装。两端都需校验固定公钥的发布清单、大小与 SHA-256；不覆盖用户数据。
- 两端系统提醒能力不同：macOS 可预约关闭 App 后的提醒；Windows 当前只有 App 内提醒摘要与状态，尚未支持系统弹窗和原生预约。
- 共享文件夹 / Syncthing 沿用既有加密操作协议；实际 Syncthing 跨机传输和临时调课后自动重排全部余时未完成。回执只证明本机处理结果。
- 搜索无正文的固定兜底、思考数字亮度调整及独立玻璃可变刷新率控制尚未提供。
- 图片上传与本地保存已提供，真实模型识图、下载、推理和工具调用尚未验证。

## 下载与安装

- macOS：`ASTaria-0.1.0-beta.12-mac-arm64-adhoc.dmg`。
- Windows：`ASTaria-0.1.0-beta.12-win-x64-setup.exe` 与 `ASTaria-0.1.0-beta.12-win-x64-portable.zip`。
- 同时提供 SHA-256 校验文件、两端签名发布清单和小写 `install.txt`。

更新前导出备份、退出旧版。JSON 备份不包含 API Key 和同步密钥，图片属于备份中的本机业务数据；同步恢复密钥须另存至共享目录外。完整步骤见[安装说明](./INSTALL.md)，网络与同步边界见[安全说明](../SECURITY.md)。
