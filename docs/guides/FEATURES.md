## 版本范围

最新公开版本是 **Beta12.1（`0.1.0-beta.12.1`）**，提供 macOS 13+ Apple Silicon 与 Windows x64 安装包。v1.0（`1.0.0`）尚未发布；本文说明当前源码的产品行为，新增能力不代表 Beta12.1 安装包已提供。

**v1.0 首次加入 Android 与 iOS，覆盖 Android 手机、iPhone 和 iPad。** 移动端尚未正式发布，安装方式和最低系统要求将在发布时公布，当前没有公开安装包。macOS 的 Developer ID 签名与 Apple 公证尚未完成，Windows 未完成实机验证，iOS 键盘与窗口交互仍在完善；正式支持的平台和安装要求以发布公告为准。

逐版变化见 [v1.0 发布说明](../releases/v1.0.0.md)和 [Beta12.1 说明](../releases/history/v0.1.0-beta.12.1.md)。

## 析熙与模型连接

- 在首页或工作台专注页与析熙对话，可以记录、拆分、安排事项，修改截止日期与状态，整理长期目标。信息足够时直接执行；缺少关键条件或需要改变已确认安排时再询问。也可以要求只记录、不安排。
- 桌面可连接 DeepSeek、常见云服务预设、OpenAI 兼容地址，以及本机 Ollama / LM Studio；手机云模型目前仅支持 DeepSeek API。
- 模型的思考深度和表达个性分别设置。等待阶段显示简短进度标题，正文开始后收起；完整思考仍可展开、收起和复制。
- 生成中的文字不代替操作回执：保存成功后才显示真实结果，失败或未完成部分单独说明。断线重试接续原请求，避免重复创建。
- API 服务与聊天网站会员分别计费，使用能力取决于所选模型和供应商；工具调用与图片理解需所选模型支持。

## 图片、文档与回复排版

- 点击发送按钮左侧的圆形 ＋ 选择图片，图片也可拖入聊天；选择后先预览，主动发送才交给模型。
- v1.0 每条消息支持一张不超过 10 MiB 的 PNG/JPEG/WebP，最长边 8192 像素、总像素不超过 16,777,216，保留原图。Beta12.1 的图片上限仍为 2 MB。
- 支持 PDF、DOCX、XLSX/XLS、CSV/TSV 文档阅读，长文档可继续读取。旧 Word `.doc` 请先另存为 DOCX 或 PDF；Word 嵌图、表格图表与宏暂不解析。
- 图片理解取决于模型的视觉能力。文档阅读与课表导入是不同入口，目前没有专用的 Excel 课表上传向导。
- 回复支持轻量表格和数学公式，分式、次方、下标、根号可直接排版；复制保留原文。
- 草稿与附件保存在本机，保存失败保留输入；断线后可沿用原请求重试。附件随请求发送给所选服务，不进入跨设备同步。

## 联网搜索与网页读取

- 联网搜索默认关闭。开启后，关键词搜索与公开网页读取使用 DeepSeek 官方搜索与网页读取服务，复用已有 DeepSeek API Key。
- 搜索请求只包含查询词或用户提供的网址，不额外附带整段聊天、课表和记忆。搜索后如需写入事项、日历或记忆，需要在下一条消息明确确认。
- 工具收到完整 HTTP/HTTPS 地址时，由本机服务直接读取公开网页正文，不必先被搜索引擎收录；网页内容不能取得本机写入权限，不登录、不执行页面脚本。
- 来源在正文下方去重并默认折叠，可展开核对链接、读取状态和时间，最多保留 6 条；没有取得正文的网页不能作为已核实依据。来源列表不等同于网页全文存档。

## 上下文与记忆

- 模型名旁的圆环显示**最近一次实际请求的上下文占用**：包含这次带入的历史对话、资料、工具以及当前输出。它不是所有请求的累计计费量；逐轮相加会重复计算。接口有用量统计时使用实际数据，缺少统计时明确显示估算。
- ASTaria 按实际内容占用控制上下文，历史不会因超过 160 条消息而截断。DeepSeek 1M 模型自动输入预算为 900K，约 800K 起整理历史，为后续工具与回复预留空间；本地模型自动预算为 24K，未知容量的兼容服务为 48K。自定义预算与关闭应用限制的选择保留。
- 需要压缩时使用有来源的摘要和检索带入较早内容；大量旧历史无法一次摘要时，明确提供未带入的范围和分页检索入口。压缩影响发送副本，不删除本机聊天原文。
- 撤回对话、忘记记忆和关闭历史只限制后续上下文，完整聊天仍可在对话记录中查看。记忆可查看来源、更正或忘记，临时记忆带有效期。

## 事项、集合与安排理由

- 同主题、同一截止日期的多份作业可收拢为事项集合，首页和工作台显示集合入口；每份作业仍独立估时、安排和完成。已有事项也可手动归类，集合详情展示共同信息及各分项。
- 日期提醒与执行型任务分开处理：仅记录考试日期、生日或纪念日时不默认占用任务时间；复习、作业等按真实可用窗口安排。已知具体起止时间的考试、会议或临时课程作为单日活动保存。
- 准备任务可关联另一项活动或任务的开始时间，例如复习必须在考试前完成。目标改期后联动检查相关安排；锁定时段、已开始事项或空档不足时保留受保护的安排并说明缺口。
- 创建回执可快捷修改截止日期和预估时长。修改估时后按同一事项和最新日程检查冲突再调整；直接修改 DDL 不会擅自挪动已保存时段。
- 重复任务按日期独立记录进度，每次优先安排完整时段；空档不足列出未排日期。创建与安排可以一起撤销，后续已被手动修改的记录受到保护。
- 析熙根据真实课表与安排结果生成简短、基于事实的安排理由，可在金色回执及工作台「建议依据」中查看，集合也支持共同与分项说明。

## 首次使用与导入

- 首次使用先显示外观、析熙个性、帧率与画质的配置摘要，点击「保存并继续」即可进入下一步；详细设置按需展开。手机玻璃底色浓淡与界面主题、通透／磨砂独立选择。
- 截图课表与 ICS 导入可从首屏进入，确认后返回继续设置，已选配置保留。模型连接步骤说明本地模型与云端 API 的区别，提供 DeepSeek 官方密钥入口、获取步骤和用量计费说明；可选择「稍后配置」，先使用离线事项和日程。
- 首页、余时、日程、工作台和弦轨的操作导览直接在真实页面中操作。提示默认收起，可展开、返回上一步、跳过或直接开始，不为导览挤窄工作区；工作台没有事项、仍在读取或读取失败时可以继续，弦轨预览只读。完成或跳过后保存引导状态，已有事项、对话或配置的升级用户不会被要求重新设置。
- 截图导入依次选择图片、识别、选课程代码与分组、核对并保存。不同原始代码保持独立，未知代码或时间需要补齐或移除，教室可留空；返回保留草稿，确认前不写入日程，保存不覆盖已有课程，可整批撤销。
- 截图识别需要已连接的模型支持图片。可选「精细识别」保留原图并补充带表头的局部裁片，表头范围可调整；没有图片也可手动录入课程。核对页支持按节次统一填写全周起止时刻，单双周课程需指定第一周周一；同格多个候选需明确选择，未补齐的信息不能直接确认导入。
- 课表截图单张不超过 10 MiB，精细识别时原图与裁片合计不超过 20 MiB，草稿最多 300 行。ICS 文件不超过 1 MiB，最多展开 1000 个事件、日期跨度不超过 366 天，重复课程必须有结束日期或次数。
- ICS 导入在本地解析，无需模型或密钥。支持有限的每周／隔周规则，按实际日期预览后保存；全天、跨日、无限重复及不支持的时区规则会明确提示。预览默认不选中课程，可按科目、地点筛选并逐行编辑，只有勾选的课程会保存。

## 日程与安排

- 从左上角 ASTaria 进入「日程」：月视图观察截止日期与忙闲分布，周视图显示课程、固定活动、休息、空课与任务时段，日视图展开一天的完整时间线。月／周／日切换保留选中的日期，并展示对应日期的可支配时间与出门准备。
- 每周安排可选择每周、单周或双周，并明确指定第 1 周的周一；单日调课使用目标日期所在周的课表，历史快照保持原样。未记录的空白不计为空闲，可支配时间只统计明确的空课或自习，并扣除固定活动、休息及已安排任务。
- 首次使用默认加入周一至周五 18:00–20:00 晚自习，可自行修改，也可自己录入课程、空课与时间。核对完成后可点击「已核对完成」，之后仍可编辑每周安排。
- 点击课程可记录地点及所需物品；点击任务可填写准备说明、携带物品、是否需要提交，并添加或锁定时段。出门清单汇总当日需要的物品，保留来源及「建议」标记。
- 完成任务与确认提交是独立状态：已经做完但还没提交的事项仍会提醒，实际提交由用户确认，也可撤回确认。
- 已确定日期和钟点的会议、校庆、临时课程等作为单日活动保存，独立于任务与每周课表；首页与日程都显示活动并支持直接编辑。
- 系统提醒默认关闭，需在 macOS App 的「设置 → 通知」允许「ASTaria 提醒」：课程、单日活动和已安排事项提前 5 分钟，明确时刻的 DDL 提前 30 分钟，仅日期的 DDL 当天 20:00。提醒遵循免打扰时段，已过提醒时刻不补发。
- 未来 30 天内最近的 64 条预约交给 macOS，关闭窗口或退出 App 后仍可触发；修改、完成、删除后会更新预约，关闭开关会取消。长期不打开 App 时不会超出这批预约继续生成。系统权限、专注模式和关机影响送达；定位、设备感知和析熙立绘尚未接入。

## 余时、弦轨与接力

- 从左上角 ASTaria →「余时」管理持续学习目标。可设置优先级、每周最低频率、单次时长偏好和阶段目标，默认单次 20–40 分钟。新目标保存后安排未来七天，之后每天首次打开应用补充安排，按实际空档分散到不同日期并留出休息；暂停不再新增安排，频率无法满足会显示缺口。
- 手机余时页通过顶部「目标／已安排／心愿」切换，分别管理目标、查看今天或未来七天的时段与留白、开始心愿对话，切换保留编辑内容；桌面继续并列展示目标与安排。
- 析熙可读取目标、时段与反馈，调整重点、频率和时长，补排空档，并记录某次学习完成而不结束长期目标。过去的安排不算完成，用户逐段记录完成、学习反馈和下次接着做的内容。
- 待考虑心愿保存尚未成为任务的愿望，可编辑、暂停、恢复、移除或设置有效期。机会提示依据真实空闲，但不会自动创建任务或占用日程；点「聊清楚」可在原有析熙对话里逐步明确动机、第一小步和条件，确认加入余时后才成为自动安排的目标。
- 点击首页右侧黑洞或余时的「弦轨」入口，镜头靠近事件视界边缘，今天、明天、后天逐日查看；组名常驻，点开组后事项沿同一条地平线展开，退出沿原路回拉。
- 弦轨读取这三天内**已经安排且尚未开始的真实任务段**供调整。今天已开始或已结束的时段保留原位，锁定时段同样不可移动，未排进日历的待办不会自动加入轨道。
- 首次进入尚未保存分组的日程，先显示本地按目标和分类整理的初稿，再由当前模型智能分组；已保存的分组会保留，想重整时可点「智能整理」。模型失败会说明原因，仍可使用原分组手动调整。一次提交最多调整 128 个可移动任务段。
- 拖动组调整当天顺序，拖到顶部日期可整组换天；展开后可以调整组内顺序，键盘方向键也可排序，Alt 加方向键换天。「调整分组」支持改名、拆出事项、合组和跨组移动。
- 点击「完成」才提交草稿：先在本地检查真实空档与截止时间生成初排，再由当前模型微调具体时刻，核对通过后整批保存并随日程持久化，提供撤销回执；模型超时、失败或校验失败均保留原日程，不写入部分安排。
- 桌面专注页按计时、任务步骤、析熙聊天排列；移动端用顶部「专注／步骤／析熙」入口或左右滑动切换，计时、步骤进度与聊天草稿保留。在右侧聊天粘贴作业要求，析熙可以把当前任务拆成可勾选的步骤；勾选或取消勾选后立即保存，全部勾选不会自动完成整项任务或确认提交。
- 点击与专注按钮并排的「留个接力」会暂停计时，在同一面板记录进度、卡点、下一步和材料；保存后回到计时界面，返回专注会保留未保存草稿，已保存的记录下次进入可恢复。

## 设置与外观

- 设置使用独立页面，分为通用、析熙、时间安排、通知、外观与动画、数据。「析熙」统一管理模型连接、个性、主动程度与记忆；通知页左侧为提醒设置，右侧为变更记录，可按全部、未读、已读、已撤销筛选。
- 其他设置包括启动页面、默认专注休息、排程缓冲、晚自习和周末可安排时段、免打扰、网格、玻璃预设和信息密度。数据页提供无 API Key 的 JSON 备份和显式确认恢复，恢复会使旧方案及旧操作快照失效。
- 「外观与动画」提供光潮、弦光、引星、关闭四种黑洞回应，以及轻柔／标准／鲜明强度和减弱动态。「思考时显示数字」独立控制黑洞内部下落数字的外观，亮度可单独调整；视频与静态背景同样叠加思考数字和弦轨光效。
- 「卡片装饰线」提供左右对称、仅左侧、隐藏三种选择；课程、安排和同类小卡片沿用各自状态色，金色可安排框和选中轮廓保留。
- 模型偶尔把提问显示为普通文本时，应用会把完整的单个提问恢复为问题与快捷选项；截断、混合或未知内容会显示可读错误，不执行文本中的写操作。

## 视频与静态背景

- 实时渲染、视频和静态图分别可选。内置 1080p 高码率视频与 4K 静态图，包含深浅主题及横竖屏；可选 4K 视频不属于安装包内容，也尚未开放下载。解码性能因设备而异。
- 推荐首页/聊天目标 60 FPS，手动档位保留；工作区背景最高 30 FPS，页面镜头运动沿用首页所选预算。画质与帧率独立，页面隐藏时暂停绘制。
- 视频模式不代表已测得的功耗收益；思考数字亮度可独立调节，与界面主题、玻璃通透／磨砂和手机玻璃底色深浅互不混淆。

## 本机数据与备份

- 桌面数据保存在本机：macOS 为 `~/Library/Application Support/ASTaria/`，Windows 为 `%APPDATA%\ASTaria`；手机数据留在应用私有目录。
- API Key 使用系统凭据保护（macOS 与 iOS 钥匙串、Windows 系统凭据、Android Keystore），不包含在普通备份与跨设备同步中。
- 设置的数据页可导出 JSON 备份并在确认后恢复；备份包含聊天和附件，当前总容量上限 32 MiB。恢复会使旧方案与旧操作快照失效。
- 请求模型时，相关对话、资料和日程会发送给用户选择的服务；本机存储不等于模型请求离线。

## 跨设备同步（桌面共享文件夹 / Syncthing 现有目录）

- 入口是「设置 → 数据 → 跨设备同步」。选择普通共享文件夹，或选择用户已经用 Syncthing 共享的本地目录（需要 `.stfolder` 标记）。每台设备保留自己的数据库，所选目录只传加密的不可变操作文件。
- 新建组选择新目录，原设备把恢复密钥导出到共享目录之外，新设备选择加入并输入 64 位密钥。手机暂不提供目录同步。
- 暂停停止目录读写，本机变更继续排队；恢复后按 30 秒周期扫描，支持手动检查并在系统唤醒时检查，最近检查时间会保留。界面显示待处理原因和最近 20 条事务回执；**回执只表示本机已记录事务，不是远端送达证明**。
- 不同字段的改动自动合并，同字段冲突可保留本机或重新核验传入内容；删除不会复活旧记录，锁定、时间重叠与 DDL 冲突进入待处理。日程按字段整体合并，可能需要人工处理。
- 同步内容为任务、分类、课程日程、安排、目标和完成记录；不传 API Key、模型路径、聊天、附件、记忆、思考与原始对话回执。退出组保留本机数据和共享文件；撤销设备必须使用新目录、新密钥和新组。
- 传输软件由用户自备：ASTaria 不安装、不配置 Syncthing，也不修改防火墙或配对设置。真实 Syncthing 跨机传送尚未验证；单次操作上限 16 MB、单轮最多检查 20,000 个文件，日志不压缩。不要直接复制或共享运行中的数据库文件。
