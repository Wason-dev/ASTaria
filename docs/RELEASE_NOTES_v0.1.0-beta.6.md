# ASTaria 0.1.0-beta.6

这个版本已上传 [GitHub Releases](https://github.com/Wason-dev/ASTaria/releases/tag/v0.1.0-beta.6)；上一版说明见 [0.1.0-beta.5](./RELEASE_NOTES_v0.1.0-beta.5.md)。

适用于 macOS 13+、Apple Silicon（arm64）。发布包采用 ad-hoc 签名，尚未 Apple 公证。更新前建议先在「设置 → 数据」导出备份。

## 本次更新

- **长期按周计划**：在「余时 → 添加目标」粘贴多周大纲，保存后可「交给析熙细化」学习步骤。只将第一个未完成阶段安排进真实空档；完成记录达到该阶段设置的次数后推进，下一次排程再安排后续阶段。未来阶段保留大纲，重新安排保留完成记录与固定时段。
- **默认值**：新安装与恢复默认时，思考档位为「低」、析熙个性为「中」；用户已经明确保存的设置不会被覆盖。
- **析熙**：调整表达，减少重复措辞；真实效果以实际使用体验为准。
- **玻璃与浅色**：优化玻璃渲染与浅色模式切换时的层次和过渡。
- **通知**：调整通知组件注册以规避旧组件冲突，系统通知显示仍待安装包验证。
- **首页**：左下角标语统一为「让时间有引力」。
- **性能**：继续减少后台唤醒、重复状态更新和绘制分配；玻璃渲染与弦轨过渡减少重复绘制和无效写入，不降低原有分辨率、辉光、采样质量或特效强度，减少动态效果设置照常生效。

## 已知边界

- 视觉与流畅性结论以本机手测为准，尚未完成其他机型和长期使用复核。
- 浅色模式进入弦轨会逐渐过渡到深色地平线；本版没有新增浅色地平线。
- 阶段依据实际完成次数推进，不按自然周跳过，也不代表已经掌握知识；成果回顾和更丰富的长期计划视图留待后续版本。
- 反馈时请附 macOS 版本、Mac 型号和复现步骤，不要上传 API Key、课表或私密聊天记录。

软件层面的工作量变化不等于真实 Mac 的功耗、温度或续航承诺，实际流畅度与省电感受仍以本机体验为准。
