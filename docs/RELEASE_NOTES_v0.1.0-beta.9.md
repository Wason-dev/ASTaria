# ASTaria 0.1.0-beta.9

适用于 macOS 13+、Apple Silicon（arm64）。安装包采用 ad-hoc 签名，尚未 Apple 公证。

## 本次改动

- 联网搜索会为每条来源抓取网页正文，并标记为抓取成功、抓取失败或正文为空。只有成功取得正文的来源可用于核对事实或日期；失败与空正文都按「无法核实」处理，不从标题、摘要或时间信息推断日期。没有可核实正文时，析熙直接说明无法核实，并逐条列出各来源的抓取状态与抓取时间（同一回合已生成写入回执时以回执为准）。联网搜索仍是设置中显式打开的独立开关，只发送查询词。
- 新增日历例外：假期、临时停课、临时调课与恢复原安排，可一次覆盖连续日期区间（最多 31 天）。例外独立于每周课表，不删除任务与单日活动；设置临时调课时指定来源课表星期。日历与日程会把例外标注在对应日期与当天标题上，单日例外可撤销并恢复每周安排。
- 析熙回复下方的快捷选项改用与其他控件一致的 8px 圆角与中性描边，键盘焦点使用金色描边，并补齐按下状态。
- GSAP 3.15.0 的官方许可正文随第三方声明一起打包，并与包版本、许可声明和文件校验和固定；打包前会拒绝缺失、被改动或过期的许可清单。
- README 的五张截图用虚构演示数据重新生成，画面来自真实页面状态，不含个人课表、聊天或密钥。

## 验证与边界

- 发布包需通过 App 签名、DMG 校验和镜像内第三方声明核验。
- 系统通知的实际显示、长期使用时的帧率与功耗、干净机器上的首次启动仍需设备验收。Windows、Intel Mac 和多设备同步不在本版范围。
- 联网搜索的实际抓取结果取决于目标站点：反爬、超时、非 HTML 内容或空页面都会按失败或空正文如实报告。
