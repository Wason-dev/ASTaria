# Beta11 技术记录索引

Beta11（`0.1.0-beta.11`）于 2026-10-08 作为预发布版本发布，内容与验证范围见 [Beta11 发布说明](RELEASE_NOTES_v0.1.0-beta.11.md)和[发布记录](releases/beta11-acceptance.json)。

本版本引入 Windows 标准安装版的应用内更新，并调整了聊天交互就绪和玻璃采样。历史测量及其适用条件保留在[性能记录](PERFORMANCE.md)中；Mac 测量不代表 Windows 体验已经通过验证。

当时工作区环境渲染的 60 FPS 上限是历史策略，现行策略见[省电与渲染决策记录](POWER_AND_RENDERING_DECISIONS.md)。更新实现时应采用现行约束，保留历史比较条件，不能将取消帧率限制或降低画质描述为同质量性能提升。

源码验证使用隔离的临时资料。安装包应对应明确的源码提交，分别核对平台、版本、资源与签名；真实设备的安装、交互和升级结果需独立验证。

当前版本的功能与安装方式见 [v1.0 发布说明](RELEASE_NOTES_v1.0.0.md)和[安装指南](INSTALL.md)。
