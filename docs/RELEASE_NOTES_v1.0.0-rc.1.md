这是 v1.0 的本地源码候选，尚未公开发布，**本机候选已构建完成**。最新公开安装包仍为 [Beta12.1](https://github.com/Wason-dev/ASTaria/releases/tag/v0.1.0-beta.12.1)。本机候选包括 macOS arm64 的 ad-hoc 签名 DMG 与 ZIP、Windows x64 的 setup.exe 与 portable.zip、Android 的 debug APK；iOS 只有工程、没有 IPA。没有公开 Release、公开下载链接或公开更新签名清单。下文记录源码行为、已完成的检查及发布前的待完成项。

## 日程与析熙

- 2026-10-18 源码/预览调整：桌面“日”视图将课程、活动、任务及已知空档按时间横向排列，只有真实重叠才上下并列，取消按类别纵向拆分和宽标签自动增行。主面板继续在上、日视图在下，复用日程主题与切日动画；手机排版不变。当前安装包尚未包含这次修改。

- 只告知考试、生日、纪念日或截止日期时，可以仅记录事项与日期，不再默认占用 30 分钟。执行型待办继续使用实际可用空档；用户明确要求「不安排」时，后续工具也不能擅自补排。
- 新增、编辑和导入每周安排，以及修改共用首周时，已经结束的历史重叠不再阻止保存。接收同步操作时采用相同的周期课表边界，保留历史、锁定与完成记录；今天仍在持续、未来重叠，以及单日课程或活动的真实冲突继续校验。
- 析熙执行临时「当天使用另一星期课表」时，自动为同日尚未开始、未锁定的冲突任务寻找最近完整空档。保留任务时长、日期、截止与分组，任务之间保留休息间隔；本次课表与最多七段移动在一个事务中保存、一起撤销。没有合适空档、已开始、已完成或已锁定时保留原安排，返回具体未完成原因。用户可要求只改课表、不挪任务；提议模式不自动执行。其他类型的日程修改与跨日重排不属于此能力。
- 长对话连续读取时去除发送副本里重复的来源索引，保留完整原文、可检索来源、最新工具结果与原生思考轮次；不提高用户设置的上下文上限。

## 图片、网页与回执

- 2026-10-18 源码/预览：析熙回复支持轻分隔线透明表格与本地字体的 LaTeX 数学排版，分式、上下标与根号可读，保留原文复制；不增加回复模板。数学引擎按需加载。
- 输入区新增模型名与上下文圆环，DeepSeek以1M为满环，使用最近实际请求的接口用量或明确标注的估算，未更改应用压缩与思考预算。详情卡片复用首页点击事项后的玻璃、圆角和关闭动效；浮层覆盖范围内不透出聊天文字，关闭后恢复原内容和焦点。已检查首页与工作台、深浅主题和 320/390px 排版；示例用量来自隔离测试数据，尚无本轮原生设备或安装包验收。
- 2026-10-18 后续修复：打开用量卡片不再使原面板磨砂失效；设置选择器复用同一分层裁切，并修正浅色主题浮层遮罩额外变暗。原玻璃参数保持不变，新增固定高频背景和文字探针对照；源码与桌面/手机预览已更新，尚未打包或取得原生设备结论。
- 2026-10-18 录屏补充：修正用量卡片关闭时短暂露出原始背景的问题，原磨砂从退出第一帧接管，卡片和原内容连续交接，关闭跟随实际动画完成；设置选择器共用修复。用量卡片的内外圆角、边线及设备像素边界重新对齐，保留原均匀磨砂。退出中间帧和自然播放另行验收，未打包。

- 每条一张 PNG、JPEG 或 WebP 的上限提高到 **10 MiB**，最长边 8192 像素、总像素 16,777,216；原图不自动压缩。首页与工作台专注聊天继续使用「发给析熙」左侧圆形 ＋ 和拖图，预览位于输入框下方。
- 待发送正文与原始附件转入本机 IndexedDB，轻量发送标识留在窗口会话存储。实际保存成功后才请求模型；保存失败保留输入，中断重试沿用原请求 ID。图片仍不参与目录同步，JSON 备份仍有 32 MiB 总容量限制。
- 桌面直接读取 GitHub 仓库时提取 README/主要内容，过滤登录状态、导航和站点壳。实际抓取本仓库得到 README 正文，不再把登录切换提示当作正文摘要。
- 搜索失败或正文为空时，把真实状态交给模型结合问题回复，不用固定的失败段落覆盖正文。来源在正文外默认折叠、去重展示；抓取成功不等于页面事实已经核验。历史已保存的旧回复不被重写。
- 手机仅通过固定匿名 GitHub API 读取公开仓库 README 与 Release 信息，拒绝认证、私网、自定义端口及重定向，不支持任意网站直取。手机真实业务链路验证了直取不走关键词搜索、来源独立保存及重开后的恢复。
- 正常回复、未完成状态与可撤销回执继续分开。成功安排的时刻在回执明细核对，不再用程序成功清单覆盖析熙的正文。

## 动效与后台负载

- 2026-10-18 源码/预览：思考数字增加独立50–300%亮度设置，默认125%；常规设置移除弦轨四项细调，保留既有效果。修复设置分区键盘焦点外框被裁切。此批修改尚未更新安装包。

- 2026-10-17 源码/预览修复：黑洞测地线两张查表纹理统一保留 Float32，由着色器完成四点/两点插值，取消对可选浮点线性过滤及 Float16 降级的依赖。低能力设备原先使用半精度时约增加 6 MiB 纹理存储，额外采样成本以实机为准；不改帧率预算、积分精度或场景特效。本机 GPU 数值与固定画面对照通过，旧 iPad 真机和新安装包待验收，详见性能记录与决策 P23。

- 余时进入、退出弦轨的独立镜头运动沿用保存的首页帧率：推荐 60 FPS，手动 30/45/60/90/120 均保留；停稳后才回到工作区背景 30 FPS 上限，中途返回同样按实际运动状态判断。
- 帧率分区仍是明确的省电取舍，未改变手动画质、分辨率、采样、辉光、Windows 玻璃设置或动画时间。转场期间允许更多绘制，不能据此声称耗电下降或 Windows 卡顿已经解决。
- 黑洞内部 `1010101` 字形基础发光由 `0.00052` 调为 `0.00070`，仅略微提亮数字。Mac 真实 GPU 六组 A/B/A 对照中，浅色最大增加 1、深色最大增加 2 个 8 位颜色单位；黑洞轮廓外及关闭数字的控制组一致。这是视觉修正，不计作性能收益。
- 弦轨调整分组面板的日期切换增加 300 ms 淡入位移，支持系统减少动态效果，保留焦点、重命名和当前编辑状态。
- 桌面同步目录只缓存已认证且成功接收的操作文件，文件身份或内容指纹变化时重读，待处理与失败记录继续校验，手动检查强制完整复验。协议、冲突处理和加密边界不变；减少重复文件读取不等于已测得功耗或续航收益。
- 2026-10-13 修复余时切换日历时的重复计算与玻璃恢复延迟：未变化的日程快照保留引用，周历/月历模型按数据和时钟变化重新计算，首次显示立即恢复准确玻璃几何，后续动画缩放仍等尺寸稳定。事项编辑、同修订号的余时完成记录、调休、分钟及跨午夜更新继续生效；保存期间的刷新合并到保存结束后，失效读取不覆盖新结果。
- 同负载隔离生产页面的月历重入日期对象创建量减少约 98.6%，8 组月历样本的最长 RAF 间隔由约 33.3–33.4 ms 降至 16.8 ms；首次加载仍出现单次 33.3 ms 样本。测量保留 ultra 画质、分辨率与工作区背景 30 FPS，浏览器 RAF 不等于显示器呈现帧率，Windows 原生与功耗仍待验收。条件与历史见[性能记录](PERFORMANCE.md)。

### 手机共享性能修复（2026-10-15 本轮增补，未发布）

- 只读事务不误标脏、已有快照无实际升级时不重写，导出后恢复外键与超时配置；超出 64 MiB 的未确认修改会被拒绝并回滚，后续读取与小规模编辑仍可继续，真实存储失败保留冻结语义。连续 20 轮四种只读请求验证整库导出与保存均为 0 次。
- 会话按请求聚合思考与回执归属、批量读取轻量 turn 字段，40 ms 撤回/删除监测不再解析整份 progress；半浮点、Base64 和上下文汉字计数减少临时分配，HTML 解析器按需加载。图片异步编码、历史图片异步解码仍保留原字节。弦轨跳过完全不可见的描边/渐变，相同尺寸不重分配画布。
- 手机聊天正文为 13px、Android 编辑控件 14px；iOS 编辑控件保持 16px 防止聚焦缩放。竖屏首页与展开聊天均进一步右移黑洞，中心黑色区域主要在右半部，吸积盘延伸到左半边；点击入口、星点和弦轨空间投影共享相机坐标。桌面、横屏及飞行终点构图保留；这是视觉调整，不计为性能收益。
- 手机性能批次当时的源码 2,205 项、手机主题/材质/宽度矩阵 1,790 项通过；类型检查、桌面/手机生产构建通过。缺少新版 WebView API 的独立流程 229 项通过，以上均为本机隔离环境。Android 最终离线构建/lint 通过（288 tasks、0 错误、14 警告、原生单元测试 NO-SOURCE），v2 debug 签名与 29 项资源字节一致检查通过，APK 已在原路径更新（29 项为该批当时值；该 APK 与本节其他包已在 2026-10-15 晚批次被替换，最新批次为 52 项）。iOS 仅同步资源，未编译、无 IPA；该手机批次当时没有重打桌面包，后续批次已另行更新。

- 黑洞 2048×1536 光线路径 LUT 的同一 RK4 积分移到独立启动 Worker，typed-array 转移回主线程并缓存一次；主线程不再做约 300 万格积分，积分数据一字节不改，分辨率、采样、星图与亮度未变，桌面仍用原同步路径。生成期间界面可挂载并保留已选主题、相机与设置；Worker 失败显示场景错误，不伪造成功或同步重算卡 UI。
- 原生数据库 Base64 编解码与既有字节校验留在数据库 Worker；主线程只做受限 Base64 串检查，加上原生 `write temp`／读回原串精确相等／`rename`／`finally` 清理。64 MiB 上限、SHA 与数据库快速检查、保存确认、失败冻结回滚保留，数据文件与格式不变。
- 长对话分离静态历史与流式正文，完整快照相等的行与回执复用并缓存 markdown；来源内容或回执变化、思考变化、跨 topic 与午夜快捷日期仍更新，不删历史或内容，估时发回与草稿附件保留。
- 手机本地只合并“同时进行、路径和 headers 相同”的 GET，不缓存已完成结果；写入开始与结束隔离，取消一个调用不误取消其他调用，POST 与 SSE 不合并，只减少重复 Worker 往返与查询，不延后数据新鲜度。
- `appStateChange` 即刻发本机 activity 事件，主黑洞、弦轨等动画、相机采样、可见轮询与分钟时钟同时尊重原生 inactive 与 `document.hidden`，回前台刷新恢复，窗口失焦不等于隐藏。
- `visualViewport` 的 resize 按 RAF 合并，同值不反复写 CSS 变量或键盘标记；首页相同尺寸不重复发布 layout 状态，最终尺寸和 safe-area 不变；同一帧合并事件会让视口标记最多延后一帧，原生键盘时序仍待真机检查。
- Android 自动玻璃默认使用系统通透／6px 磨砂，手动精细折射保留；iOS/WKWebView 原本走 CSS fallback 继续保留，Mac 与 Windows 规则不变。这是玻璃边缘位移的视觉取舍，不能记作无损提速，黑洞质量与帧率未变，设置文案已同步。
- 现有工作区 30 FPS 上限、转场预算、手动画质与帧率档位不变。**本轮没有 iOS/Android 真机帧率、内存或功耗数据**，不能据此声称 Windows、Huawei 或 iPhone 真机流畅或通过功耗验收；原生产物和具体测量结果分别记录于本文件与性能记录，不把源码或构建检查当作设备验收。

### 手机排版与面板体验（2026-10-15 本轮增补，未发布）

以下记录 2026-10-15 的本地排版与面板改动，仍为未发布源码。本节不声明测试数量、构建或产物状态，这些按验收记录单独维护。

- 手机外壳未变：手机仍由原来的 `BlackHolePrototype` 与 `HomeWorkspace` 首页承担，品牌导航、字体、聊天展开与弦轨沿用既有组件；没有额外析熙导航，适配写在共享组件内部，不是第二套界面。首页去掉与导航重复的时钟，分钟时钟仍随后台活动边界暂停。
