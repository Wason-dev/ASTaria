# ASTaria 0.1.0-beta.3

这次更新让已安排的余时目标可以直接在工作台开始，并提供 GitHub 更新下载与安装。

- **工作台余时入口**：具体安排开始前 20 分钟出现；当天过时但未完成的安排仍可继续。完成和撤回只作用于选中的这一段，工作台、日程、余时同步，长期目标和其他日期保留。安排被移动后要求重新选择。
- **App 更新**：在设置中检查 GitHub 发布，查看说明、下载并校验，再安装并重启。支持取消下载和失败重试；替换前核对安装包与 App，启动未成功会尝试回退。使用公开发布信息，不上传本机事项、课表、对话或模型密钥。
- **性能**：减少隐藏页面的轮询和动画唤醒、重复状态更新和页面写入，保留原来的渲染分辨率、辉光、流动与特效强度。
- **日程**：当天事项以左右按钮翻页，完成余时只完成本次安排。
- 合入此前的余时跨周续排、安排结果提示，以及窗口控制和本机状态同步修正。

适用于 macOS 13+、Apple Silicon（arm64）。本包使用 ad-hoc 签名，尚未经 Apple 公证。首次安装受系统拦截时请按附件安装说明操作。旧 Beta2 需先手动安装本版一次，之后可在设置内安装后续更新。更新前建议导出备份。

长期使用、干净机器和休眠恢复仍需在实际使用中验证；软件统计显示后台工作减少，但不代表实际瓦数或续航承诺。
