# ASTaria 0.1.0-beta.4

这次更新补上隔周课表、退出 App 后的系统预约提醒，以及从心愿继续聊清楚的入口。包含 Beta3 的性能优化、余时工作台和 GitHub 更新安装。

- **隔周课表**：每周安排可选择每周、单周或双周，设置第 1 周的周一。跨年连续计周；日程、空档核验与提醒使用相同规则。单日调课按目标日期所在周选课表，过去的记录保留。
- **系统提醒**：在「设置 → 通知」开启并授予 macOS 通知权限。已安排事项、课程、单日活动提前 5 分钟，明确时刻的截止提前 30 分钟，仅日期的截止当天 20:00。遵循免打扰时段，不补发已经过去的提醒。完成、移除或改期后重新同步，关闭开关取消预约。
- **退出后仍提醒**：预约交给 macOS，不需要后台常驻进程。一次最多预约未来 30 天内最近的 64 条；打开 App、恢复使用、修改日程及运行期间定期补充。长期不打开时仅覆盖已交给系统的这一批；系统权限、专注模式与关机会影响送达。
- **心愿澄清**：余时的待考虑心愿可点「聊清楚」，在原有析熙对话里逐步明确动机、第一小步和条件。已确认信息写回同一份心愿，保留普通聊天草稿；只有明确选择加入余时后才自动安排。
- GitHub 更新下载沿用 macOS 系统代理配置，修复桌面网络接口遇到安装包重定向时中断的问题；每次跳转仍核验目标地址。

适用于 macOS 13+、Apple Silicon（arm64）。使用 ad-hoc 签名，尚未 Apple 公证。Beta3 可从设置下载并安装本版；Beta2 及更早版本需手动安装。更新前建议导出数据备份。
