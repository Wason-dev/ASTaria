# ASTaria 0.1.0-beta.8

适用于 macOS 13+、Apple Silicon（arm64）。安装包采用 ad-hoc 签名，尚未 Apple 公证。

## 本次改动

- 首次启动可选择析熙个性浓度、玻璃质感和深浅背景；API Key 可以导入，也可以稍后设置。引导会打开真实的首页、余时、日程、工作台与只读弦轨预览，完成后进入首页。
- 弦轨的智能分组和完成排序固定使用低思考强度，即使聊天选择了更高档位；聊天仍可单独使用原设置。已生成的分组结果随当前日程快照复用，手动点击「智能整理」可重新生成。
- 弦轨超过一屏的组通过位于可见中轴的箭头浏览；处理过程显示实际读取、核对、排程和保存活动。重试先核对已写入结果，避免重复安排。
- 浅色模式下余时和设置玻璃保留阴影；从余时进入弦轨时减少突变。心愿展开减少重复折射计算，保留 Beta7 的玻璃控件过渡。
- 更新页采用一致的玻璃与低饱和金色反馈，安装位置提示说明如何处理。

## 已知边界

- 系统通知的实际显示、长期使用时的帧率与功耗、干净机器上的首次启动仍需在设备上验证。
- Windows 和多设备同步不在本版范围。
