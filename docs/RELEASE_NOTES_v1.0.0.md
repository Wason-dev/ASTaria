# ASTaria 1.0.0 · 发布说明

> v1.0 尚未发布，发布日期未定。本文汇总 Beta12.1 之后的主要产品变化；发布时提供的功能、平台与安装要求以正式公告为准。

[官网](https://astaria.space) · [官网源码仓库](https://github.com/Wason-dev/ASTaria-website) · [安装说明](INSTALL.md) · [变更记录](../CHANGELOG.md)

## 发布状态与平台

最新公开版本仍为 Beta12.1（`0.1.0-beta.12.1`）。v1.0（`1.0.0`）尚未发布，正式发布前没有公开下载。

- **macOS 13+ Apple Silicon（arm64）**：Developer ID 签名与 Apple 公证尚未完成。
- **Windows x64**：继续提供安装程序与便携 ZIP，未完成实机验证。
- **Android 手机与 iOS（iPhone、iPad）**：本版首次提供；安装渠道与最低系统要求将在发布时公布，当前没有公开安装包、IPA 或 TestFlight 邀请。

可选 4K 背景视频不属于安装包内容，也未开放下载；默认安装提供 1080p 高码率视频与 4K 静态图。安装要求与操作见[安装说明](INSTALL.md)。

## 首次推出 Android 与 iOS 移动端

**v1.0 是 ASTaria 首次推出移动端的版本，新增 Android 与 iOS，覆盖 Android 手机、iPhone 和 iPad。** 此前公开的 Beta12.1 提供 macOS 与 Windows 桌面版；本次把事项、日程、析熙对话、余时目标和工作台专注带到移动设备。

- 为手机与平板适配触控导航、系统安全区、软键盘和横竖屏布局；手机专注页可在计时、步骤与析熙之间横向切换，iPad 可利用更宽的显示空间。
- 事项、日程、对话与设置保存在当前设备，支持备份导出与恢复；移动端 API Key 使用系统凭据存储。手机与桌面的资料不会自动云端同步。
- 移动端析熙目前支持 DeepSeek API；桌面其他 API、本地模型及共享文件夹同步暂不提供移动入口。

移动端随 v1.0 首次发布，安装方式、分发渠道与最低系统要求将在发布时公布。

## 首次使用与上手教程

- 首屏改为快捷配置摘要，外观、析熙个性、帧率和画质可一次保存；详细选项按需展开。手机玻璃底色浓淡与界面主题、通透／磨砂分别选择。
- 截图导入课表与 ICS 导入直接放到首次设置中。核对并保存后可返回继续设置，已选的外观等选项保留。截图识别需要支持图片的模型；尚未连接时也可先导入 ICS 或手动录入课程。
- 模型连接说明本地与云端的区别、API Key 获取步骤、官方入口和用量计费说明，帮助区分 API 服务与聊天会员。可以稍后连接，先离线记录事项和日程；桌面也可从引导进入其他 API 或本地模型设置。
- 首页、余时、日程、工作台与弦轨的操作导览改为默认收起的浮动提示，可随时展开，不再为教程压缩工作区；支持上一步、跳过此步和直接开始。
- 工作台导览按实际事项状态显示提示，没有可开始事项或仍在读取时可以继续；弦轨导览提供只读预览，切换日期和返回不会重新安排任务。
- 完成或跳过后保存引导状态；升级时已有事项、聊天或配置的用户可直接继续使用原有资料。

## 析熙：对话与执行

- 优化事项与排程的对话流程，减少重复读取和无必要的追问；信息足够时直接完成操作，缺少关键条件或需要改动已确认安排时再询问。
- 保留用户选择的思考深度，改善长回复、流式中断和重试的衔接。等待时显示简短的思考进度标题，正文开始输出后收起；完整思考过程仍可展开、收起和复制。
- 已保存的操作继续显示真实回执，重试避免重复创建。回复已完整保存时，自动清除因连接中断遗留的「回复还没完成」提示。
- 回复支持轻量 Markdown 表格与数学公式，分式、次方、下标和根号更易阅读，复制保留原文。
- 模型名旁显示上下文占用圆环，包含当前实际带入的历史对话、资料、工具和本次输出；区分估算与服务返回的统计。
- DeepSeek 1M 模型自动输入预算为 900K，约 800K 起整理历史，为工具结果与回复预留空间；短对话不会仅因消息较多就提前摘要，自定义与关闭限制的设置继续生效。
- 减少长历史对话中的重复读取；实时资料与历史快照明确区分，放不下的历史明确保留检索入口，不把未带入的内容当作已读。
- 记忆等工具执行前已经输出的正文会保留，后续回复接着显示，重新打开对话也不会丢失。
- 支持上传 PDF、Word（DOCX）、Excel（XLSX/XLS）及 CSV/TSV 表格供析熙阅读，图片上限提高到 10 MiB，长文档可继续读取。
- 带附件的请求发送失败后保留原文与附件，可沿用原请求重试；刷新当前页面也能恢复待确认的发送记录。
- 可选联网搜索改用 DeepSeek 官方搜索与网页读取，复用已有 API Key。来源在正文下方去重、默认折叠，可查看链接、读取状态和时间；正文为空或读取失败会明确标注，不能当作已经核实的资料。
- 断流后确认已完成时同步清理未改动的发送草稿，保留后来编辑的内容；异常退出后的失败消息可按原请求继续重试。
- 优化对话记录面板、复制反馈和发送状态；仍可通过对话要求「只记录、不安排」。

## 模型连接

- 桌面新增 OpenAI、通义千问／百炼、硅基流动、智谱及自定义 OpenAI 兼容服务入口，可填写 API 基础地址与准确模型 ID。各地址的密钥独立保存，切换地址不会沿用另一个服务的密钥。
- 连接与密钥保存状态分别提示，保存失败保留输入；测试针对当前保存的服务，并区分「API 可用」和「工具调用可用」。预设用于简化填写，具体识图与工具能力仍由所选模型决定。
- 桌面继续支持 Ollama、LM Studio 等本地模型；使用本地或其他 API 模型时，可单独配置 DeepSeek Key 用于官方联网搜索。手机目前仅支持 DeepSeek API。

## 事项与安排

- 同主题、同一截止日期的多份作业可归为事项集合，首页和工作台默认收拢；每份作业仍独立估时、安排和完成。聊天中的创建回执逐项显示 DDL 和预估时间编辑，不必先展开；整批撤销仍在创建结果中操作。
- 工作台支持手动归类已有事项；集合详情按实际安排时间展示，宽屏并列排列。
- 修改回执中的预估时长后，析熙会读取原事项和最新日程，检查冲突并调整同一事项的安排。
- 准备任务可关联到另一项活动或任务的开始时间，例如把复习安排在考试之前。目标改期时联动检查相关安排；遇到锁定时段、已开始事项或空档不足时保留原安排并说明原因。
- 析熙根据真实课表与安排结果生成简短理由，展示在金色回执及工作台的「建议依据」中；集合支持查看共同与分项说明。
- 日期提醒与可执行任务分开处理，考试日期、生日等提醒不再默认占用任务时间，也不混入「现在可以开始」的任务推荐。

## 日程与课表导入

- 桌面日视图按时间横向排列课程、活动、任务与空档，减少纵向堆叠，保留真实重叠与编辑入口。
- 手机日历提供周摘要、单日明细和月视图；平板日程使用更充分的横向空间。
- 截图导入按选择图片、识别、选课、核对、保存分步进行；返回保留草稿，等待时显示识别进度。
- 截图导入提供可选的精细识别，保留原图并补充带表头的局部裁片，表头范围可调整；没有图片时也可直接手动录入课程。
- 总课表支持按科目与课程代码选课，保留原始代码，跨周复用已选分组；识别不清的格子留给用户补充。
- 核对时可按节次统一填写全周的起止时刻；单双周课程需确认第一周的周一。同一格存在多个候选或信息不完整时，先选定、补齐或明确移除，再保存；确认后整批导入并可整批撤销，不覆盖已有课程。
- 导入前可逐条修改或删除课程，确认后才保存；ICS 在本地解析，无需模型或 API Key，支持有结束范围的每周／隔周重复，并提供预览、确认与撤销。不支持的规则会明确提示。
- ICS 预览可按科目或地点筛选，逐条勾选要导入的课程，并修改日期、时刻和地点；默认不全选，只有明确勾选的课程才会写入日程。
- 已结束的历史冲突不再阻挡新课表，正在持续和未来的冲突仍会检查；临时调课时处理同日未开始、未锁定任务的冲突。

## 余时、工作台与弦轨

- 手机余时页提供「目标／已安排／心愿」三个视图，分别管理目标、查看时段与留白、开始心愿对话；切换保留正在编辑的内容，桌面继续使用并列布局。
- 弦轨调整日期时优先寻找最早的真实空档；整段放不下时提供分段或保留整段等可选方案，确认后才保存。
- 因截止日期无法换天时，可在原位置快速修改 DDL，并保留已调整的分组草稿。
- 弦轨只重排尚未开始的时段；已开始或结束的安排保留原位，不因事项尚未勾选就挪到今天剩余时间。「保留原时段」清单可查看原始时段及保留原因。未改动直接退出，等待期间原时段开始则要求重新读取。
- 工作台任务步骤翻页加入连贯动画；移动端专注页可在「专注／步骤／析熙」之间点选或左右滑动，切换保留计时和草稿。

## 外观与交互

- 手机设置改为单列六入口，左侧统一图标；顶部导航作为浮层展开，不推动下方内容。
- 手机玻璃深浅可独立调节，默认淡档减弱原主题底色，与界面深浅主题、通透／磨砂分别设置；首次使用即可调整。
- 改善上下文、对话记录、活动编辑与事项集合浮层的轮廓和层次，打开时保留后方界面，减少玻璃闪烁与关闭时的亮度跳变。
- 手机聊天面板利用可用宽度，左右边距一致；首页通知胶囊放在底部页脚，与聊天面板及标语错开，长通知可点开详情。
- 调整键盘收起后的聊天面板恢复曲线；移动端展开析熙不再自动打开键盘；明显超宽的公式显示细滚动条。
- 移动端导航与各页内容上移，首页聊天框上下留白保持平衡；选择浮层始终保留磨砂，改善通透模式下的选项可读性。修正 iPad 窗口缩放后聊天高度未恢复的问题。
- 移动端的思考、复制、撤回和回执文字增强对比度；日程菜单和导入窗口位于导航下方，返回菜单时保留玻璃外壳。
- 焦点提示沿控件圆角显示，由方向键或 Tab／Shift+Tab 导航触发；字母输入不再意外唤出直角焦点框。
- 桌面与 iPad 系统菜单加入新建对话、页面跳转、析熙开合与使用说明，并提供键盘快捷键。
- 黑洞思考数字亮度可单独调整，范围为 50%–300%，默认 125%。背景新增本地视频与静态图模式，内置 1080p 视频和 4K 静态图，思考数字及弦轨光效叠加在媒体背景上；可选 4K 视频未开放下载。
- 减少重复背景素材，缩小安装包体积；后台暂停不必要的播放和绘制。桌面图标使用银灰三瓣黑底样式，DMG 提供清晰的拖入安装引导。

## 本机数据与备份

- 手机和平板支持在应用内保存事项、日程、对话与设置，未连接模型也可使用本机记录；API Key 使用 iOS 钥匙串或 Android Keystore 保存。
- 手机备份可通过系统分享面板保存或分享 JSON 文件，也可选择备份恢复；普通备份不包含 API Key，恢复前会明确提示替换当前资料。
- 桌面目录同步减少对未变化文件的重复读取，文件变化和待处理操作继续核对，手动检查仍会完整复验。共享文件夹与 Syncthing 入口继续保留，手机暂不提供目录同步。
- 附件原件只保存一份，减少图片和文档占用的本机空间与备份大小；兼容旧数据和备份，重试仍核对原附件。恢复备份保留当前设备的提醒开关。

## 使用范围

- 图片和文档的理解能力取决于所选模型。旧版 Word `.doc` 请先另存为 DOCX 或 PDF；Word 嵌图、表格图表与宏暂不支持解析。
- Excel 文档阅读与课表导入是两个入口；目前不提供专用的 Excel 课表上传向导。
- 联网搜索请求只包含查询词或用户提供的网址，不额外附带整段聊天、课表和记忆。搜索后如需写入事项、日历或记忆，需要在下一条消息明确确认；来源列表最多保留 6 条。
- 思考深度选项用于 DeepSeek；其他 API 与本地模型沿用各自服务行为。其他 API 应填写公开 HTTPS 基础地址，本地连接仅支持本机服务；具体模型能力请通过连接测试确认。
- 视频模式的解码性能因设备而异。iOS 键盘与窗口交互仍在完善，未列为已解决。
- 可选 4K 背景视频不属于安装包内容，尚未开放下载。
