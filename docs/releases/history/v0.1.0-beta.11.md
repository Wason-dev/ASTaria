# Beta11 · 0.1.0-beta.11

本轮是 macOS arm64 与 Windows x64 的体验完善预发布版本，重点处理切换页面、展开与收拢聊天。[Beta11 Release](https://github.com/Wason-dev/ASTaria/releases/tag/v0.1.0-beta.11) 已公开为预发布，提供 Mac 与 Windows 安装包。Windows 切页与展开聊天仍存在卡顿，体验仍未达标，Windows 包仍为试验版。

## 本次更新

- Windows x64 标准安装版加入应用内更新：在设置中检查更新、下载并校验（发布清单签名、SHA-256 与大小），退出 App 后静默安装并重启；启动确认失败时把旧版本移回并尝试重新启动，回退本身失败会提示需要人工恢复。便携版或非标准安装位置只能手动运行安装包。
- 修复聊天输入与焦点需要等待相机动画完全停稳的额外延迟，保留原有动画轨迹、画质与材质。
- 帧率分区保持原有省电设计：首页与聊天沿用所选 90/120 FPS，工作区黑洞与环境渲染最高 60 FPS，30/45 档不升档，返回首页恢复所选帧率。
- 修复高刷新率屏幕上的误跳帧；减少玻璃渲染与页面切换中的重复计算和无效写入，保留原有画质、分辨率与特效强度。
- 隐藏页面会停止后台绘制，保留页面内容、编辑状态与滚动位置，返回时恢复。
- Windows 切页与展开聊天的体验问题仍在处理。

## 支持范围与未完成项

- macOS 13+ Apple Silicon：ad-hoc 签名，未 Apple 公证；DMG 仅提供 Applications 快捷方式，由用户手动拖拽安装。
- Windows 10 x64：提供安装程序与完整便携 ZIP，未做操作系统代码签名；Windows 11、更多 GPU/DPI/多屏、睡眠恢复与长期功耗尚未验证。
- Windows 标准安装版已有应用内更新；便携版或非标准安装位置仍需手动运行安装包。Windows 10 的真实自动升级与失败回退尚未实机验证。BetaX → Beta11 首次升级需手动下载并运行新的 `setup.exe` 或解压新的 portable ZIP。
- Windows 手动「精细折射」仍可能明显慢于默认玻璃；不能承诺所有场景无卡顿。
- 本地模型的实际下载、GPU/CPU 推理与工具调用尚未完成验证。
- 共享目录 / Syncthing 同步与密钥安全边界继续适用；实际跨机传输仍未验证，事务回执不代表其他设备已收到或应用变更。
