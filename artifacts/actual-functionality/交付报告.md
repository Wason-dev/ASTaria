# ASTaria · 第一条任务星辰

基线：`8030ca5`。开发分支：`feature/actual-functionality`。

## 可运行的闭环

打开默认视界或 `#/black-hole`，点击「投放一粒星辰」，填写任务名称和可选备注。保存成功后，任务成为外轨节点；点击节点或用 Tab、Enter 打开详情，将状态改为「进行中」，节点移到内轨并显示双光环。完成后节点收拢至视界，任务保留在「回望」中，可再次打开并重新开始。刷新后任务、备注和状态仍在。

默认信息密度为「沉浸」，不展开表单；「工作」显示节点名称与状态；「分析」补充截止时间、可见数量和轨道含义。名称、状态、日期均为 DOM 文本。星图索引可搜索全部现有任务，包括出屏、搁置和完成的任务。

## 结构与冻结边界

- `src/spatial/scene.ts`：任务到场景的纯映射、相机只读契约、空间事件、CSS 像素投影。
- `useSpatialTasks.ts`：沿用 `taskStore` 和 `astaria-local` IndexedDB，使用 Dexie `liveQuery` 同步同源标签。写入成功才更新节点；失败保留输入，支持重试；同步防重复提交。
- `SpatialUI.tsx`：DOM 节点和 SVG 轨道，不操作 shader uniforms。
- `ReadablePanels.tsx`：原生对话框、任务创建、详情、状态修改、索引和完成记录；隔离快捷键并恢复焦点。
- `TaskWorkspace.tsx`、`useSceneCamera.ts`、`spatial.css`：组合业务与场景，只在相机切换时采样实际取景，完成动效遵循减少动态设置。
- `BlackHolePrototype.tsx`：仅新增组件接入、只读 snapshot getter 和键盘事件边界。原渲染器生命周期、镜头按钮与参数逻辑保留。

`BlackHoleRenderer.ts`、`shaders.ts`、`geodesics.ts`、`postprocessing.ts`、`StarInfall.ts`、`prototype.css` 六个文件与基线 SHA-256 完全一致，见 `frozen-baseline.json`。observer distance 30、全景/星际预设、统一弹簧与鼠标 Gaussian 场均未修改。`main` 仍是 `8030ca5`。

```sh
npm run typecheck
npm run build
node --test scripts/spatial-scene.test.mjs
node scripts/verify-spatial.mjs
node scripts/verify-spatial-storage.mjs
```

- `typecheck-output.txt`、`build-output.txt`：类型检查与生产构建原始输出。
- `scene-tests.txt`：7 项场景契约测试，覆盖状态/历史过滤、稳定排序、输入不可变、节点上限与超量选择、桌面/移动投影、DPR 和非法日期。
- `browser-checks.json`、`browser-output.txt`：生产预览端到端检查，覆盖创建、焦点/键盘、状态、持久化、回望和重开、原镜头预设、390px 布局、减少动态与运行异常。
- `storage-checks.json`、`storage-output.txt`：7 项独立浏览器检查，覆盖跨标签同步、创建/更新/首次读取故障及重试、同步重复提交、未捕获异常。Codex 独立重跑通过。
- `screenshots/`：1440px 桌面创建、节点、详情、回望、日间，以及 390px 昼夜与详情截图，已逐张检查主要布局。
- `frozen-baseline.json`：冻结文件哈希与分支基线核对。
- `change-summary.txt`：本次变更文件与行数统计。

浏览器端到端脚本默认访问 `http://127.0.0.1:5188/`，需先在 9227 端口启动独立临时配置的 Chrome。存储故障脚本访问 5177 开发服务，自行启动/关闭 9228 临时 Chrome，仅在测试标签注入 store 故障。测试任务不写入用户的正常浏览器配置。

## 当前范围

这是任务创建、状态与回溯的一个垂直切片。未加入自动排程、AI 解析、依赖引力线、风险推断、协作或完整日志系统。原 `#/app` 继续使用原任务库。

轨道是图像平面的可读空间索引，按状态分内外轨；不声称模拟任务的物理引力。每条轨道最多绘制 6 个候选节点，出屏或过近的节点通过索引访问，界面显示实际可见数量。历史保留任务和完成时间，尚无完整状态事件日志。

数据保存在当前浏览器、当前源（协议/主机/端口）下；5177 与 5188 的数据库相互独立。本次未增加云同步。

构建继续有单个 JS chunk 超过 500KB 的提示。本次没有重新做全套 P0 性能录制，不新增任何全设备 60fps 承诺；现有 P0 性能结论仍以原交付报告为准。存储错误注入验证恢复流程，不等于物理磁盘故障或配额耗尽测试。
