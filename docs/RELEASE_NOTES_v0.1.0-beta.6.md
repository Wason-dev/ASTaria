# ASTaria 0.1.0-beta.6

这个版本已上传 [GitHub Releases](https://github.com/Wason-dev/ASTaria/releases/tag/v0.1.0-beta.6)；上一版说明见 [0.1.0-beta.5](./RELEASE_NOTES_v0.1.0-beta.5.md)。本页列出本次改动与手测项目。

适用于 macOS 13+、Apple Silicon（arm64）。发布包采用 ad-hoc 签名，尚未 Apple 公证。更新前建议先在「设置 → 数据」导出备份。

## 本次测试内容

- **长期按周计划**：在「余时 → 添加目标」粘贴多周大纲，保存后可「交给析熙细化」学习步骤。只将第一个未完成阶段安排进真实空档；完成记录达到该阶段设置的次数后推进，下一次排程再安排后续阶段。未来阶段保留大纲，重新安排保留完成记录与固定时段。
- **默认值**：新安装与恢复默认时，思考档位为 `low`、析熙个性为「中」；用户已经明确保存的设置不会被覆盖。
- **析熙**：精简提示词，真实模型效果待手测。
- **玻璃与浅色**：优化玻璃渲染与浅色模式切换时的层次和过渡。
- **通知图标**：调整版本号以规避旧组件注册冲突并增加诊断，系统显示待安装包手测。
- **首页**：左下角标语统一为「让时间有引力」。

## 性能升级

本版继续按「先减少无谓工作，再谈画质」的方向收敛后台唤醒、重复状态更新和绘制分配，前台仍保留必要的数据刷新；玻璃渲染与弦轨过渡减少重复绘制和无效写入，不降低原有分辨率、辉光、采样质量或特效强度，减少动态效果设置照常生效。这些只是软件层面的工作量变化，做法与既有对比记录见[性能说明](./PERFORMANCE.md)：其中的空闲计数来自隔离环境的软件统计，能说明后台工作减少，但不等于真实 Mac 的功耗、温度或续航承诺，实际流畅度与省电感受仍以本机手测为准。

## 手测清单

安装本次发布包后请逐项确认；未通过的项目请附复现步骤反馈。

- [ ] 长期计划：粘贴一份按周大纲，保存并交给析熙细化，确认当前未完成阶段排进空档、未来阶段保留大纲。
- [ ] 长期计划：完成当前阶段要求的次数后，下一次点击安排才排入新阶段；撤回完成后进度恢复。
- [ ] 长期计划：重新安排之后，已完成记录和固定的时段保持原样。
- [ ] 默认值：新安装或恢复默认后，思考档位是 `low`、个性是「中」。
- [ ] 默认值：手动改过档位与个性后重启，设置没有被覆盖。
- [ ] 析熙：多轮对话里重复表达明显减少，长回合仍然稳定。
- [ ] 玻璃：透明与磨砂两种模式下，余时、设置和聊天面板层次正常。
- [ ] 浅色：浅色模式下阴影与边界可以分辨；浅色余时进入弦轨不再突然变黑。
- [ ] 切换：页面切换、弦轨进出和快速反向操作没有明显卡顿或跳变。
- [ ] 数据：更新前导出的备份可以导入，事项、日程和专注记录没有丢失。
- [ ] 更新：本次发布包可以正常打开，原有本机数据保留。
- [ ] 通知：在「设置 → 通知」发送测试提醒，检查系统通知包含 ASTaria 图标、标题和正文；预览仍遵循 macOS 隐私设置。

## 已知边界

- 视觉与流畅性结论以本机手测为准，尚未完成其他机型和长期使用复核。
- 浅色进入弦轨会逐渐过渡到深色地平线；本版没有新增浅色地平线。
- 阶段依据实际完成次数推进，不按自然周跳过，也不代表已经掌握知识。成果回顾和更丰富的长期计划视图留待后续版本。
- 反馈时请附 macOS 版本、Mac 型号和复现步骤，不要上传 API Key、课表或私密聊天记录。
