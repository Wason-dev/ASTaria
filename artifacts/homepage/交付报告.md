# 首页实现与验证

日期：2026-09-16

开发分支：`feature/actual-functionality`，本轮开始于 `2fa7263`

## 本轮范围

- 左上角 ASTaria 下拉导航，支持悬停、点击和键盘；使用与析熙面板一致的自适应折射玻璃，工作台、时间表、日历、DDL 保留为未启用入口
- 首页仅显示两行当前任务、下方小尺寸「交给析熙」药丸，以及左下角「把今天交给我」
- 移除首页观测台、昼夜按钮、镜头按钮、轨道节点和旧任务面板
- 药丸为 128 × 38 CSS px，与当前任务相距 12px；同一玻璃表面展开为左侧聊天区域
- 首页和聊天区域保持黑色主题；收起后返回首页
- 支持本地事项录入、详情和状态修改；输入第一行作为标题，其余内容作为备注
- 当前任务按进行中优先、截止时间、创建时间排序；使用真实本地数据，无示例任务
- 草稿在同一浏览器标签页内保留，支持关闭聊天后重新打开及页面刷新
- 本轮未接入 DeepSeek，不产生模拟 AI 回复；自然语言拆分、排程、课表、日历和聊天黑洞特效留待后续讨论
