# 渲染与后台性能

beta.3 的优化不降低原有分辨率、辉光、采样质量或特效强度。重点减少没有必要的 JavaScript、网络轮询和内存分配。

- 共享设置订阅、忽略内容相同的数据快照；专注计时仅在运行阶段刷新。
- 页面隐藏时移除轮询计时器，返回时刷新；弦轨组详情隐藏时取消动画循环。
- 弦轨复用曲线采样容器与路径临时点；只有变换或路径变化时才写回 DOM。
- 黑洞帧记录使用固定容量循环缓冲区，避免持续移除长数组首项；重复画质配置不再重建帧调度。

2026-09-29，以同样的临时数据库、独立 Chrome 配置和减少动态效果设置，对比 9 月 28 日优化前构建与 beta.3 源码。前台首页空闲 20 秒：

| 软件指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 250 ms 计时回调 | 80 | 0 |
| 15 s interval 回调 | 2 | 0 |
| React 提交 | 9 | 0 |
| 设置读取请求 | 2 | 1 |
| 任务／会话读取总数 | 8 | 8 |

前台仍保留必要的数据刷新。以上对比涵盖两阶段优化的累计效果；不等于第二阶段单独收益。减少动态效果条件用于隔离后台工作量，并不代表动画开启时的 GPU 成本。软件渲染测试不能推出真实 Mac 功耗、温度或续航百分比。

复现：桌面构建后运行 `node scripts/verify-idle-performance.mjs`，通过 `IDLE_QA_BASELINE` 指向原基线构建。测试只操作临时数据库和浏览器，不操作现有数据。弦轨几何、辉光连续性和动态边界由 `scripts/horizon-renderer.test.mjs` 验证。长期硬件功耗与不同屏幕刷新率仍需实机测量。
