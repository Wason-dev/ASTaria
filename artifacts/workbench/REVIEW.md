# 工作台与 Upcoming DDL 可调预览 · 2026-09-17

分支：`工作台`，从 `6895c5d` 创建，未修改或合并 `main`

## 体验入口

打开 `http://127.0.0.1:5188/`，展开左上角 ASTaria，选择工作台

- 首页仍为「交给析熙」，展开后的聊天与日程共用 680 × 460 的连续玻璃，窄屏按可用空间收缩或切页
- 工作台自动转为白色，回首页恢复黑色，使用已有昼夜接口和镜头预设
- 「示例预览」提供独立样例，方便在没有真实事项时调布局；样例不会写入任务数据库
- 「自定义」调整布局、字体、玻璃、背景、信息显示，可复制参数、恢复默认，参数存于本地
- 默认双列、宽 900px、字号 12px、事项最小高度 96px、间距 8px、位置 108px、通透度 80%、磨砂 0px、圆角 24px、边缘 0%、阴影 11%、背景 15%

当前本地预览使用 `npm run build:preview`。`npm run dev` 同样保留调试工具；`npm run build` 为正式构建，去掉自定义和示例入口，并忽略本地保存的外观调试参数。专注时长调整作为真实功能保留

## 本轮工作台调整

- 左侧展示「现在可以开始」「稍后安排」「已完成」，后两区默认保持展开，空区也有清楚说明
- 右侧 Upcoming 按时间显示已逾期、即将截止、后续；越急的提醒字重、字号和暖色越明显，远期收敛为蓝灰色
- 暖白底、偏冷的透明玻璃、深色文字配少量香槟色，保留用户选定的小尺寸与材质参数
- 窄屏标题下先显示一条紧凑的截止摘要，点击后带动画定位完整 Upcoming 列表；侧拉栏 DDL 也指向此处
- 日期型截止按当地整天结束计算，并标注「全天」；具体时间按实际时区计算。无日期不虚构 DDL，非法日期提示待确认
- 点击任务或 DDL 都进入同一专注流程，返回后恢复来源位置与键盘焦点；完成后移出 Upcoming，在已完成区保留时间与专注记录
- ASTaria 侧拉栏的阴影移到独立图层，使用与玻璃相同的 220ms 淡出；折射父层保持静止，避免星际视角采样方向跳变

## 专注流程

先选一项，再点击开始专注。选择本身不改任务状态，开始时标为进行中；完成事项才写入完成状态。完成后停留在当前事项，可选择下一项

默认 35 分钟专注 / 5 分钟休息，可分别调整为 5–120 分钟（5 分钟步长）和 1–30 分钟。尚未开始的计时采用新设置；已运行或暂停的本轮保持原时长，下一轮使用新值

离开工作台、返回选择、切换示例都会暂停并保存进度。浏览器后台节流通过墙钟校准，不累积 tick 误差。到时仅提示，不自动完成任务、不自动开始休息或下一轮。休息不计入累计专注时间

任务选择、专注切换、完成记录、DDL 定位、时长设置、自定义与主题过渡保留动效，支持减少动态偏好。键盘选择、返回、完成和弹层关闭均恢复到可见焦点
