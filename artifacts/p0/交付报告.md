# ASTaria P0 · 黑洞原型交付

实现位置：`/Users/2026-2027/ASTaria`。启动：`npm run dev`。默认入口与 `#/black-hole` 均显示原型；既有应用保留在 `#/app`。本次只完成 P0 黑洞，未开始 P1 业务功能。

## 最终画面与操作

- 默认全景：距离 0.70×、倾角 83°、旋转 18°，中心位于屏幕横向65%。
- 星际近景：保留原有舒适构图（倾角84°、旋转7°、中心横向98%），距离推进至2.35×；着眼点距离从30降至6.5，并与横向、旋转使用同一临界阻尼轨迹，形成身处吸积盘近场的穿行感，而不是先缩放再横移。
- 视界保持正圆；吸积盘通过倾角变薄。夜间和白昼圆边、无透镜直达分支与细光子环均使用几何导数覆盖率抗锯齿；纸纤维只影响材质，不再位移黑洞轮廓，避免黑白模式边缘锯齿。
- 同一盘面由 Schwarzschild 测地线查表获得最多三次交点，形成前盘、上方透镜弧和下方次级像。纹理按半径差速流动，角速度系数保持1.9，没有提高转速。
- 吸积盘使用不等距密度流束、局部透明度、白热内盘和选择性光晕。已撤回后来增强纹理起伏的一轮修改。
- 星图最高8192×4096，50,000颗确定性星点。远处星点保持清晰，近处光线受透镜弯折；10条错开相位的环境微光轨迹，另有用户触发的星辰坠落。
- 鼠标小黑洞：约4px暗核、4.7px细亮环；黑暗区域仍可见。星空、吸积盘与Bloom同步扭曲。已删除产生巨大外沿的着色器空间分支，场强连续衰减。
- D 打开观测台，空格暂停，Esc 关闭。提供昼夜、倾角、远近、旋转、四档画质/自动降级、物理分层开关与10秒帧数据导出。

环境：macOS、Apple M4 Pro / Metal、Chrome 152、生产构建。下表使用 Chrome DevTools Protocol 的真实时间线事件，记录浏览器合成与呈现反馈，不把rAF回调当成显示器实际扫描帧率。

| Ultra Retina | 2880×1800 | 59.9988 Hz | 17.5178 ms | 18.289 ms | 0 | 0 |
| Safe | 936×585 | 60.0010 Hz | 17.4078 ms | 18.138 ms | 0 | 0 |

两段各有598个浏览器呈现标记，无内部序号缺口；管线显式DROPPED为0。每段结尾2个DrawFrame尚未完成反馈，按录制边界计入，不虚构完成或丢帧。

无头浏览器采用硬件GPU，60Hz由其合成时钟驱动。这些结果支持该机器上的渲染性能，不等于所有设备保证60fps，也不声称完成了实体屏幕扫描测量。原生Chrome中已实际查看页面；本次性能证据为可导入Performance面板的CDP原始trace，而非手工面板录制。开发中曾出现GPU竞争导致的长帧，最终独立录制数据如上。

浏览器检查：1440/390px布局、白昼/黄昏/夜晚、暂停静止、真实后台标签页取消rAF、减少动态静止且控件有效、最低档、镜头连续/反向/收敛、指针离开后停止按需渲染、零运行异常。原始检查分别见 `browser-checks.json`、`camera-checks.json`、`pointer-checks.json`。

鼠标外沿回归：暂停同一帧，在星空和吸积盘两处比较激活前后截图；距指针110 CSS px以外的RGB通道差均为0。大于3/255通道差的最远像素分别距指针64.07px和67.04px，覆盖检查了先前100px和220px外沿错误；结果与截图哈希保存在 `pointer-boundary-checks.json`。

测地线6组数值验证通过，含独立积分、双倍网格对照、守恒量、盘面交点及捕获分类。trace解析器29个测试通过。`npm run build`成功；构建仍有单块JS大于500KB提示，未为压掉提示改变现有项目打包架构。

## 未完成 / 限定范围

- 没有手工完成Chrome Performance面板录制；提供的是同引擎CDP trace与分离的浏览器呈现统计。实体显示器以及其他机器上的稳定帧率仍需各自实机验证。
- 模型为非旋转Schwarzschild黑洞；不声称Kerr旋转度规、流体/辐射求解或科学可视化精度。外围星空采取清晰度优先的局部投影，近视界采用测地线方向。
- 辉光与材质采用艺术化曝光；视觉A2的2–5倍亮度比会受曝光压缩影响，代码中的Doppler因子与视角关联且不随纹理旋转。
- P1三膜业务骨架、时间河、任务输入、排程均未实现，符合本次P0范围。未来可将独立Three运行时接入桌面外壳，本次未打包桌面应用。
